# 内部架构

本文面向维护 Semlo 的开发者。公开入口仍是各包的 `src/index.ts`；下列内部路径可以随实现调整，不作为接入方的 API。

## 工作区和核心目录

- `packages/core`：编辑器、默认界面、内容格式及接入能力。
- `packages/react`、`packages/vue`、`packages/solid`：对应框架的组件适配。
- `demo`、`docs`、`tests`：体验页、文档站和回归测试。

`packages/core/src` 按职责组织：

```text
editor/         编辑器组合、实例生命周期、扩展注册和内容读写
features/       文字、列表、表格、数据表、媒体、插入等功能
integrations/   每实例宿主能力绑定与上传生命周期处理
platform/dom/   已被多个功能使用的 DOM 和弹层基础能力
runtime/        事务、选区同步、历史和通用清理
shared/         现有功能共同使用的日期和缩进规则
styles/         编辑器基础样式及有序样式清单
ui/             默认工具栏、查找、目录和其他界面
index.ts        核心包公开导出
```

组合层负责装配功能与默认界面；功能模块负责自己的文档规则和视图资源。适配器通过核心包接入，不能自行维护第二份文档状态。共享模块应有真实的多个使用者，不为了减少文件数量而把无关功能放在一起。

## 生命周期与内容

`editor/create-editor.ts` 创建编辑器并接入功能。`editor/lifecycle.ts` 协调实例及视图资源；`controlled-editor.ts` 处理宿主直接销毁底层编辑器时的清理。销毁前先标记状态，关闭资源登记后再执行释放回调，以处理回调重入和清理异常。初始化失败与正常销毁的顺序分别由组合层提供，修改时应同时验证两条路径。

内容初始化、严格解析、替换、快照和 HTML 输出位于 `editor/content/`。JSON 在解析前检查当前 schema 声明的节点和标记属性，并在解析时校验内容结构；创建失败抛出异常，替换失败通过 `onError` 报告并保留当前文档。普通 HTML 初始化仍宽松解析。内容替换先校验并比较文档，再通知旧视图和异步任务失效；HTML 输出按文档字体、有序列表和标题编号的现有顺序处理。变更时保持节点名、属性及已有 JSON/HTML 格式，并验证受控回写、撤销、旧异步结果和宿主自定义扩展。

数据表载荷在 JSON、HTML 解析及输出时检查容量和可保留性：允许补齐缺省值，拒绝损坏、超限或会被归一化丢弃的内容；HTML 数据表不因普通 HTML 宽松解析而降级为空表。编辑操作在提交前检查容量，失败时保留已提交内容、提示错误并报告 `onError`；文件选择数量超限时不调用上传服务。数据表的底层 Tiptap 节点必须携带有效数据，插入空载荷节点不再生成默认表。

结构化内容的共同底线是：不能把已接收的损坏内容、超限值或未知字段静默替换、截断后保存。功能可按自身约束选择在写入前拒绝并报告，或保留原始数据、显示不受支持并限制相关操作；安全展示只使用经过校验的投影。修改时分别检查 JSON、HTML、编辑写回和撤销，不把一种格式的检查当作其他格式的证明。现有内容类型仍需逐项核查，不能仅凭这条原则声称所有类型均已完整覆盖。

数据表、画布等现有载荷没有统一的显式版本字段，不能假定旧文档已经携带版本。未来需要演进时，应先按内容类型定义旧载荷识别、迁移和失败恢复，并保留原始数据；未知的未来版本应拒绝写入或保留为不可编辑内容。增加版本字段前须验证未版本化数据的读取、编辑、撤销和 JSON / HTML 往返；目前没有通用版本迁移机制。

默认工具栏由 `ui/toolbar/default-toolbar.ts` 分阶段装配和刷新，`read-state.ts` 读取选区、文字样式和对齐状态。浮动工具栏由 `ui/toolbar/bubble.ts` 管理容器、定位扩展和默认控件；`floatingToolbar` 工厂可替换控件，复用选区显示规则和链接弹层。组合层负责将控制器、选区同步、事务/只读订阅及实例生命周期交给两个工具栏工厂，并在初始化失败时清理；关闭或自定义主工具栏时不创建默认主工具栏，关闭浮动工具栏时不创建浮动容器，自定义浮动工具栏时不创建默认浮动控件。`toolbar` 和 `floatingToolbar` 可分别配置，未指定后者时保持原有 `toolbar` 开关行为。查找和格式刷快捷键独立装配；没有默认主工具栏时，高亮快捷键使用默认颜色。选区同步位于 `runtime/selection-sync.ts`。链接和图片地址弹层由 `editor/url-session.ts` 管理，语雀内容选择弹层由 `features/references/yuque-content-session.ts` 管理；组合层负责提供实例状态与弹层装配。插入命令、最近使用记录和菜单会话位于 `features/insertion/`。主工具栏、斜杠和块操作入口共享功能规则，但各自保留原有选区、焦点和失效时机。

本机字体入口固定在“更多”面板，其他控件仍按工具栏可用宽度移动原始节点；溢出控制器销毁时恢复原始顺序。面板使用当前编辑器的组合输入状态处理 Escape，避免在输入法组合期间关闭。

浮动工具栏定位时避让同一实例可见的主工具栏，在选区变化、视口调整和相关容器滚动时更新位置；滚动监听仅在浮动工具栏显示时存在，并在隐藏或销毁时清理。未配置主工具栏时不增加避让边界。

格式刷读取来源正文、标题或简单平铺列表项的文字及段落属性，待办还读取勾选状态；点击受支持的目标时在同一事务内转换块类型并应用格式，再将光标映射到点击位置。引用、高亮块、折叠正文、分栏和表格单元格内支持正文、标题与简单平铺列表互刷，转换前检查父容器的内容约束。有效根级编号续接可刷成正文、标题或其他列表；需要跨类型间隔时原子升级整条链，移除中间片段时连接两侧。编号项来源可将相邻正文接入该项所属序列，包括交错序列；源节点或关联失效时不推测。有效自定义起点的平铺列表也可参与这些转换，相邻旧列表保留自身起点。空块保留后续输入格式，局部拖选只写文字格式并保留选区。根级旧有序列表的中间项被转换时按操作物化编号序列并连接两侧；容器内的编号中间项尚不能建立这种续接，保持保护。标题锚点不从来源复制，目标自定义属性无法保留时拒绝转换；不同编号样式和复杂嵌套列表的转换尚未覆盖。

语雀内容选择器由 `features/references/yuque-content-session.ts` 管理，保存 `semloEditorContentReference` 行内原子节点，支持标题、卡片和嵌入模式；旧普通链接不迁移。嵌入地址由宿主的同步 `resolveEmbed` 提供且不写入内容，缺省语雀链接提示宿主配置。iframe 默认使用不透明源沙箱；宿主显式选择 `allowSameOrigin` 时允许可信跨域页面使用其自身源，拒绝直接同源地址，但不能阻止远端跳转至宿主页，信任边界由宿主负责。iframe 不发送来源引用。提供方变更先移除旧预览，解析前后核对节点、文档、实例和提供方归属；切换模式及高度以独立历史事务提交。新节点可能无法由旧版严格读取器识别，HTML 清洗器可能只保留链接。

加粗命令及选区状态位于 `features/text/bold-command.ts`，主工具栏、浮动工具栏和快捷键使用同一规则；自定义界面可从核心公开入口读取状态并执行命令。仅标题选区禁用加粗，跨标题与其他文本时保留标题格式，状态与切换方向均按可加粗的非标题内容计算。选区同步与焦点仍由调用入口按交互方式处理。

清除文字格式位于 `features/text/clear-format.ts`，主工具栏和实例快捷键共用。只清理已支持的内置格式 mark，保留链接和宿主语义 mark；按各选区范围处理，避免 CellSelection 清理单元格之间的正文。格式提交复用历史及宿主事务守卫，不能用清除全部 mark 误删链接或重置块属性。

标题和正文样式的共享命令与菜单状态位于 `features/heading/style-command.ts`，转换实现和选区分类分别位于 `conversion.ts` 与 `selection.ts`。默认菜单显式设置样式，快捷键和体验页按钮切换样式；折叠卡片跨区时菜单禁用，但快捷键仍沿用原有正文转换行为。

`heading/anchor.ts` 为根级标题提供级别按钮和段落链接。首次复制时按需生成标题身份并以非历史事务写入内容；宿主仍负责保存和文档 URL，旧标题加载时不增加身份。链接使用当前 URL 的 `semlo-heading` 参数；匹配到唯一标题后展开折叠祖先并滚动。同文档粘贴时重映射重复身份，标题拆分不继承身份，只读旧标题不写入。视图销毁清理提示、异步结果与窗口监听；旧版读取器和静态 HTML 的限制见接入文档。块操作视图统一测量标题链接、折叠按钮和操作柄的可用空间。

`heading/fold.ts` 默认在可编辑文档的标题上保存折叠属性，变更通过 `onChange` 交宿主保存，不加入撤销历史；重载时从内容恢复，旧内容缺省展开。只读交互不改文档，内容变化时按位置映射已有视图状态，并吸收新增或显式改变的折叠属性。粘贴标题会清除折叠标记，避免折叠目标文档已有的后续内容；内部拖动保留状态。显式配置 `headingFoldPreferences` 时由宿主管理折叠视图状态，既有文档标记不改写。新属性对旧版严格读取器和过滤 HTML 属性的宿主可能不可兼容。

新版编号列表的混合、中文或多级数字样式下，无续接同序列平铺单项或连续项可由 `heading/sequence-conversion.ts` 转为编号标题；优先继承已有同级标题编号样式，否则沿用列表样式。中间项使用 v3 关联保持两侧续号；列表和相邻根级正文的混合选区可在一个事务中转为标题或正文，标题按文档顺序继承编号。转换前检查宿主属性，事务校验文档并保留选区及撤销。标题转换共用 `heading/clear-inline.ts` 清除字形和字号并保留颜色、链接；标题编号的切换及样式更新集中在 `heading/numbering-toggle.ts`，由工具栏、快捷键和块菜单复用。其他编号列表的标题转换仍受保护。

根级编号列表的缩进由 `numbering-sequence-indent.ts` 与编号模型共同规划；目标层级的普通项接续相邻序列，重启序列首成员保留重启语义。有效续接的当前片段仍能核实原序列时，事务同时更新后续片段的起点，并避开整条链已有的局部身份。未选项目会因此更换父项、拆分交错序列或重启首项会丢失原归属，以及续接失效或无法核实原序列时保留原文。键盘、工具栏及块操作复用同一命令；语雀相应编号组合仍待对照。

受支持的平铺编号中间项或续接链中间片段可转换为正文和标题；来源标识随文本块保留，标题转换按需升级关联版本。`numbering-sequence-bridge.ts` 仅在完整选中转换范围且两侧平铺列表的关联、序列、起点、样式和属性可核实时接回；原有的正文或标题间隔保持不动。部分选中及不兼容情况不猜测关联。工具栏、快捷键、样式菜单和单段块菜单复用此规划，块菜单目标不借用旧选区。

`list/mixed-sequence-conversion.ts` 处理无续接的平铺编号列表与相邻根级正文同选转待办或无序列表，保留范围外列表序列、文字格式及选区。工具栏和 `list/keyboard.ts` 共用列表命令；快捷键执行前同步浏览器文本选区，同步被宿主拒绝或改写时不执行后续转换。列表及列表项存在无法转存的宿主属性时保留原文。

已有续接的根级平铺片段可按受支持范围转待办或无序项，转换整段时连接前后片段；原 v1 链在同一事务中整体升级为 v2，失效链不推断修复。转回时只在两侧序列、起点和样式可核实时接续；隔有正文或 v3 标题时保留间隔并重建片段。链两端整段转回及复杂嵌套仍有边界。

标题行选择位于 `features/heading/end-selection.ts`。已验证的行定位派发选区事务前结束本次默认按键处理，宿主拒绝、替换文档或重定向选区后不继续原生扩选。`line-selection-fallback.ts` 在当前位置无法验证但原生选区仍位于同一标题内时，阻止 `Home`、`Shift+Home` 和 `Shift+End` 的默认行为并保留选区；读取或映射选区发生异常时也停止该次行操作。回退不派发事务或新增历史事件，不强制同步旧光标；输入法、组合键、其他实例和已明确跨块的原生选区保留既有路径。

引用粘贴归一化位于 `features/text/quote-paste.ts`，只通过 `transformPastedHTML` 展开无结构化来源标记的外部 `blockquote`，不修改 HTML/JSON 文档载入和输出规则。普通复制使用 ProseMirror 的 `data-pm-slice`；块菜单的 HTML 复制在首个元素附加 `data-semlo-editor-clipboard="1"`，避免自身结构化内容被当作外部引用展开。已知语雀 `ne-clipboard[source]` 来源下，将实测可见 HTML 的 `div.ne-quote` 转为标准 `blockquote` 并保留嵌套子节点；不解码或执行 `data` 私有载荷。此规则不代表完整支持语雀剪贴板或 Lake 数据格式。来源标记只是粘贴语义提示，仍由原有 schema 和地址规则解析内容。归一化使用当前视图的 `ownerDocument`，无全局监听或共享实例状态。

`features/text/quote-keyboard.ts` 处理根级普通段落中的 `> ` 快捷输入，以及只含一个空段落的根级引用退格；快捷输入和包装使用一个事务，退格按编辑历史正常分组。输入范围与模型选区不同时，先核对真实折叠光标，再派发选区事务；宿主拒绝、重定向或替换文档时停止本次输入。带非默认引用属性的节点不走该退格路径；嵌套容器、带标记的输入和输入法组合继续沿用原有处理。

唯一根段落通过快捷键新建引用时，保留段落属性并用标准历史机制处理后续输入。实例内短期候选只接受尾部真实文字输入及快捷键转 H3，输入证据、文档结构、时间或宿主事务不匹配时失效；程序写入、追加事务及其他选区不推断为该连续操作。`heading/conversion.ts` 和 `heading/keyboard.ts` 仅在候选有效时让转换与整段删除参与已有历史分组，其余路径继续隔离历史。实际输入法尚未验收。

`features/text/paragraph-paste.ts` 在默认空白根段落接收多段正文时，保留所测带行高首段的属性；接入方粘贴处理器先接管，仍有后续处理器时交还原流程。实例内候选核对粘贴前文档、实际事务和结果，只有随后全选并快速使用行高快捷键才尝试合并历史；程序写入、非默认目标和宿主追加事务不推断为该组合。行高菜单和其他容器仍沿用原有路径。

斜杠查询的保存投影位于 `features/insertion/slash-draft.ts`。`isSlashDraftParagraph` 统一限定根级正文、顶层引用/高亮块、折叠正文及其中高亮块，以及根级普通表格直接单元格/表头内的正文段落，输入跟踪、保存和查询内删除使用同一上下文规则；标题、普通列表、折叠标题和未纳入范围的嵌套输入保持正文。`slash-history-candidate.ts` 按真实 `handleTextInput` 的输入范围记录起点与结果文档证据，不依赖可能滞后的模型选区；将查询保存状态与历史信任状态分别跟踪；只在建议仍活跃、范围覆盖同一受支持正文段落且文字一致时，从保存投影中去掉查询。查询内不触及 `/` 的纯删除逐步核对范围并保留临时态，跨出查询或带有其他修改时保留正文。快照的三种格式使用同一投影，编辑文档、选区和历史不变；载入、粘贴、程序插入、组合输入或证据失效时保留正文。普通历史重放若没有重新打开查询的证据，也保守地按正文输出。内容替换比较原文档及保存投影，避免受控回写删除活动查询；已挂载实例精确回写当前导出的同一 HTML 快照会按原字符串识别，避免合法颜色或宿主字段规范化误触替换；普通文档及其字面查询同样适用，不把不同/加工后的 HTML 或旧快照当回声。内容解析仍先执行，HTML 序列化前后核对原状态、文档与视图；进入调用前已卸载的普通文档保留原更新路径，途中重挂或销毁仍中断。退出建议等纯状态事务导致保存内容变化时，实例内的提交观察器通过已有事务监听补发 `onChange`；真正的文档变更继续由 Tiptap 通知，销毁时随原事务监听解除，不增加全局资源。根级普通表格的语雀活动查询保存刷新与 Esc 已实测，Semlo 普通单元格及表头、保存投影、历史和生命周期已回归；其他深层嵌套、更多命令与真实输入法仍待对照。折叠正文的 UI 用例等待内容可见后点击，同步 `setContent` 后立即设置正文选区仍受上游隐藏节点初始化时序限制。

链接状态、地址校验和编辑会话位于 `features/references/link-command.ts`，默认弹层、快捷键及自定义工具栏共用占位和写入规则。会话持有目标选区，在文档变更、只读、卸载或销毁时失效；调用方负责关闭未完成会话。

写作助手的宿主契约、请求归属、结果校验和接纳事务位于 `features/writing-assistant/`，默认内嵌面板位于 `ui/writing-assistant/`，是视图装饰而非文档节点。插入、斜杠、块下方及选区入口共用每实例会话，宿主通过动态 `writingService` 提供生成能力；纯文本按字面写入，结构化结果复用现有严格内容解析。目标固定在打开时的文档、视图、范围和服务；正文变更或生命周期失效后保留可复制草稿，不再回写。接纳在宿主事务回调后再次核对归属，使用历史边界分离前后编辑；只读转换的实例级 fence 防止同步中止回调重新进入旧可编辑窗口。低层重挂会重建插件集合，面板在新视图重新注册，监听随实例释放。

写作结果反馈由可选 `writingFeedback` 提供，主动点击后接收当前提示和结果副本；结果可携带不进入正文的 `feedbackId`。反馈状态和中止器属于当前实例及草稿，重新生成、目标失效、服务更换或销毁会中止旧反馈并忽略迟到结果。宿主负责实际提交与权限，不能将中止视作远端撤销。

普通块下方插入和写作接纳通过 `features/insertion/sibling-item-attrs.ts` 构造新同级列表项属性：保留缩进和格式，清除只属于源项的编号重启标记，待办新项为未完成。该策略不改变列表转换及不能安全表示内容时的保护。

列表命令及状态位于 `features/list/list-command.ts`，默认工具栏和自定义界面复用待办、无序及有序列表转换规则；不支持安全转换的复杂选区保持原内容。折叠卡片标题选区的分类位于 `features/blocks/details-selection.ts`，供列表状态和工具栏共同使用。

版本化编号序列由 `features/list/numbering-sequences.ts` 负责校验、物化和独立派生，`numbering-sequence-document.ts` 处理节点投影，`numbering-sequence-transactions.ts` 约束尚未支持的结构写入。旧数值算法统一位于 `numbering-values.ts`，原 ordinals 入口复用并重导出。列表级 `semloEditorListSequences` 是唯一序列定义，项级 `semloEditorListSequence` 只保存局部引用；默认 null 不进入公开快照；首次受支持重排或所测旧嵌套列表的跨项纯文本粘贴才原子物化。同物理列表以实际位置识别，不能依赖不可变 Node 引用的相等。

默认混合列表的罗马字形由 `features/list/mixed-roman.ts` 与 `base.css` 中同名 counter-style 共同派生，`ordinals.ts` 的可见标记、HTML 和跨项片段 plain 使用相同规则；不把当前标签写为第二份编号状态。新的静态回退只用于无显式 `type` 且列表样式缺省或 mixed 的路径；原通用 lower-roman 回退及显式类型、非默认和未知样式保留，避免改变旧 HTML 的非目标显示。序列数值、身份和快照正文不变；普通旧列表的复制路径没有因此扩张。

`numbering-sequence-clipboard.ts` 为根级同父同层单段叶项选区，以及同一物理列表中单段项组成的跨层选区生成封闭的独立普通列表；HTML 从 1 计数且不携带源身份，plain 从权威编号读取源标签并按实际层级前置每级两格，原文和复制历史不变。跨项剪切合并首前缀和末后缀并保留首身份；支持同父同层项、根项到其后代、以及两个默认编号父项之间的直接子项范围，后者将未选中的末父项子项并入首父项序列。根项到后代的末项之后不能有未选深层项；跨父项操作要求初始起点、序列及兼容属性可核实，关联片段不处理。policy 先完成剪贴板写入及回读，再核对状态、可编辑性及销毁归属，随后以独立历史事务派发。失败或未定义范围不删除，状态提示属于当前插件视图并随变更和销毁清理。完整列表和同段复制走原路径，通用结构粘贴守卫不放宽；其他跨层剪切和未定义转换仍受限。兼容取舍见[编号序列决策](../docs/adr/0001-numbering-sequences.md)。

新版编号列表的类型转换开放根级平铺单项及连续项，目标为待办或无序列表；中间范围产生 v2 跨类型续接并在前段增删时同步后段起点。目标移除序列成员和旧重启标记，逐项检查宿主属性，校验文档后以一次历史事务提交；交错序列的转换项额外记录来源边和序列，完整选中且两侧兼容时按各自身份重新接回。待办与无序项互转和拆分保留标识；完整复制换新关联，独立复制解除来源。工具栏和块菜单复用资格检查，部分复杂关联仍受保护。有效 v2、v3 关联可再次多行纯文本拆分并保留原版本；旧版和 HTML 属性过滤的限制见 ADR 0002。

跨根级续接列表复制时，`numbering-sequence-clipboard.ts` 在可核实的平铺同序列范围内重建独立关联并保留版本；v3 支持包含完整编号标题。内置 HTML 序列化会校验投影与标题，再补充源标题可见编号；宿主自定义序列化器保持优先。`shared/clipboard-hooks.ts` 区分内置列表复制钩子和宿主钩子，使未涉及编号列表的标题复制保留原有序列化规则；部分编号标题和不安全的跨块选区仍受保护。

简单两级混合编号列表中，末尾直接子项若与前一同层项属于同一序列，也可转为待办或无序项并保留缩进。转回时只在相邻有序列表、同层末项、格式及属性兼容的情况下接续当前序列；转换事务校验完整文档并进入一次历史。不同序列及更复杂层级不通过此路径。

同父同层和直接父子剪切允许选区包含完整选中的深层子树，其他未受影响的分支也可包含多段列表项及三级或更深项；跨父项剪切也允许选区内完整选中的深层子树，以及无关父项的多段或深层内容。涉及重归属的两个父项的范围外深层子树仍受保护，单段和编号资格需满足校验；末项仍有未选后代时不能猜测后代的归属。

跨根级块的复制处理独立的新版编号列表、普通正文段落和无编号标题：独立列表各自重新编号，正文与标题保留原格式。对由普通段落隔开、同一初始序列且全为根级叶项的续接列表，部分复制会建立新的关联，并按选中项数从 1 重排各段起点；验证续接计划后再写剪贴板。复杂关联列表、编号标题或其他块类型仍拒绝；此路径不开放跨块剪切，语雀对应复制结果仍待对照。

`nested-legacy-plain-paste.ts` 在所测单父直接叶项、默认属性的旧嵌套列表中，将跨项纯文本粘贴和扁平化、版本化放在同一事务；其他旧结构保持原入口。`linked-sequence-drag.ts` 仅在前后片段、默认初始序列及属性可验证时，将后段首子项提升到前段首子项之前，并在同一事务重新计算续接。

`numbering-sequence-paste.ts` 规划同层、同有效样式的封闭普通多项片段合入单个叶段落，或替换同父同层的连续叶项：合并选区首尾文字，新增成员继承首项身份，原 registry、起点、来源及范围外内容保持。目标段落与宿主声明属性须兼容；另支持所测初始编号的首根项至直接子项，未选同序列直接子项归属最后新根项，其后须为同序列根项；其他跨父层或带子项范围仍拒绝。多行纯文本在上述叶项范围拆出普通段落和另一物理列表，后半段按原编号扣除所选删除成员后设置各局部序列起点。`numbering-sequence-continuation.ts` 通过版本化前后关联连接根级片段，计算后段起点；policy 以附加事务同步编号并归入同一历史，校验溢出，完整复制时换新关联、单段复制时解除关联。删除单叶项中间片段时，只在原有前后关联完整且后段序列身份、来源可核实时重接；否则解除失效关联，不推测。已验证的三段续接空子项退格由专门规划器在同一事务内调整层级与编号；组合输入、只读、销毁或失联的视图不接管，宿主拒绝或同步撤销后不补写过期历史边界。旧内容的默认空关联不进入快照，异常字段及重复端点拒绝。跨父、带子项和其他空项结构仍需核对。policy 在实例 DOM 捕获阶段记录该事件的视图与状态，并在 schema 归整前检查保留字段和原始层级；语雀所测列表包装只读取严格检查过的可见 HTML，校验来源起点后按目标编号重建封闭片段，不读取私有载荷；通过公开的 `transformPasted` 参数识别纯文本，提交前再核对权限、组合输入和归属，以独立历史事务写入，不放宽通用 guard。监听随视图销毁释放；文件、自定义 MIME 和普通单行输入继续走已有入口。

`features/text/plain-paste.ts` 只在纯文本含连续换行时介入，按原换行创建空段落；普通文本继续使用既有默认路径。前面的宿主纯文本解析器优先，后续解析器保留原有机会；DOM 解析使用已有宿主 `clipboardParser` / `domParser` 或 schema 默认解析器，保留当前位置 marks 和空白。代码块仍走 ProseMirror 原有代码文本入口。

`integrations/bindings.ts` 为每个编辑器保存当前宿主能力并识别变更；组合层按既有顺序通知相关功能，功能自身负责使旧请求和视图失效。数据库表格、图册/看板、日历和图表视图位于 `features/database/views/`；单元格连续输入和输入法会话由 `edit-session.ts` 管理。`features/database/interactions/` 按弹层会话、单元格、字段、筛选分组排序和视图设置组织界面交互，节点视图负责装配和协调统一的事务写入。画布的数据、几何、导出、绘制、指针会话、控件和剪贴板交互分别位于 `features/drawing/canvas/`，视图通过节点视图提供的当前节点和文档代次校验操作是否仍有效。

画板、流程图和 UML 图共用画布工具栏：基础图形通过图形库选择，平移与缩放位于右上角；所选图形工具的状态由图形库入口反映。视图重绘、只读切换和销毁时仍由图形库 disposer 清除面板和监听。

`integrations/update-coordinator.ts` 维护每实例的待通知状态、失败重试和同步重入顺序；组合层只提供具体能力的装配与失效操作。数据表的记录变更基线和元数据更新位于 `features/database/record-change.ts`；日历月份和分组折叠状态由每个节点视图的 `view-state.ts` 管理，不写入文档。画布及思维导图保留无法识别的展示属性，不能安全解释时显示提示并停止相关编辑。

思维导图的中心节点结构支持向右、向左、双侧、向上、向下、四种树形和两个时间轴布局；节点视图与静态 SVG 使用相应分支方向规则。节点文字样式和链接范围保存在树节点中；链接范围以 UTF-16 偏移表示，校验顺序、重叠及代理对边界，编辑文字时映射保留范围。未知样式、范围或不安全地址按不支持数据保留，不能静默覆盖；静态 SVG 按字号计算节点空间并输出样式与安全链接。旧内容缺省布局为向右，公开 JSON 快照省略缺省属性；显式布局随 JSON / HTML 保存，未知值原样保留并阻止编辑。布局、文字样式和链接修改分别进入撤销历史。缩放和平移为节点视图的实例状态，替换文档时重置，不改变文档内容。旧版本可能无法识别新增样式或链接，或忽略、丢弃新增布局，不能保证旧写回保留。

导图分支线型保存在根节点，颜色和粗细保存在各分支节点；视图与静态 SVG 共用线型计算，子分支缺省继承上级颜色。节点的形状、填充、描边和优先级、进度、旗帜标记保存在节点数据，编辑视图和静态 SVG 均使用该数据。未知线型、样式或标记保留并阻止编辑，旧版可能无法识别新增字段。连续修改节点文字时逐次映射链接范围，输入法组合期间合并为一次映射。

单节点概要作为对应树节点的独立子树保存，节点路径以 `-1` 表示概要入口，编辑、添加子节点、删除和撤销复用节点操作。视图与 SVG 将概要纳入布局；横向结构使用概要连接线，其余结构目前按普通子节点排列。

非中心节点可保存 `subtreeLayout`，分别覆盖子树的分支、向下树形、向上树形或时间轴结构；缺省继承上层结构。编辑视图按每条连接所属父结构布局和绘制，静态 SVG 对混合子树逐层计算空间。未知值保留并停止编辑，旧版可能丢弃新增字段；复杂混合结构及静态空间估算尚未完整对照。

导图配色面板位于 `features/drawing/mindmap/color-picker.ts`，随节点视图重绘释放，不注册全局监听。颜色提交核对当前节点、文档代次与选中路径，避免旧自定义颜色弹窗在文档替换后写入新内容。

导图画布文字的可选宽高、水平和垂直对齐由 `mindmap/canvas-text.ts` 校验并随内容保存；缺省字段保持旧内容表示。节点与画布文字共用 `mindmap/text-links.ts` 校验和映射链接范围，使用 UTF-16 偏移并拒绝不安全地址、重叠和拆开的代理对。四角手柄按当前旋转角度固定对角点调整框体，指针取消、替换文档或销毁不提交旧预览；字号独立于框体。静态 SVG 使用可自动换行的 HTML 文字并为不支持者保留显式换行回退，边界估算为保守值，特殊字体与非浏览器消费器仍需核验。

导图最大化为节点视图的实例状态，切换不修改文档；返回前提交当前节点文字草稿，替换文档时退出最大化。该界面直接使用编辑器撤销历史，销毁时不留下全局监听。

导图画笔数据保存在可选的 `drawing` 属性中，笔迹使用画布内容坐标；马克笔以可选类型区分，旧笔迹缺省为普通画笔。校验点数、坐标、颜色与粗细，无法识别的数据原样保留并停止编辑。指针移动只更新草稿，松开后一次写入历史；取消、替换文档和销毁时释放指针捕获，旧草稿不写入新内容。橡皮擦按笔迹整体命中；静态 SVG 输出笔迹并扩展视野，但复杂布局的笔迹与节点相对位置仍需核对。旧版可能无法保留新增笔迹数据。

独立画布文字保存在可选的 `annotations` 属性中，按内容坐标定位；校验文字、坐标、可选旋转角度和样式，未知数据保留并停止编辑。拖动和旋转在松开时写入历史，文字草稿在完成编辑时写入，失败时保留输入；文档替换及销毁使旧操作失效。静态 SVG 包含旋转文字，视野使用文字宽度估算；复杂布局的相对位置仍需核对。旧版可能无法保留新增字段。

导图图形和连线保存在可选的 `canvasShapes` 中，复用画布数据校验、连线几何与 SVG 轮廓；支持独立图形、图形间连线及仅包含图形的单层组合，未知笔迹或嵌套组合数据原样保留并停止编辑。四种 Smart 模板复用画板模板数据，组合可整体移动、缩放、旋转、删除和取消编组；单图形缩放沿图形自身方向，旋转后的组合保持比例缩放。图形库复用画布选择面板并限制在导图区域内，关闭、重绘和销毁时释放浮层监听。拖动、旋转与缩放在松开后写入历史，文字草稿失败时保留；静态 SVG 扩展视野包含图形、连线及估算的文字范围。旧版可能丢弃新增字段。

导图连线的节点视图位于 `canvas-lines.ts`，端点可以是自由坐标、画布图形或导图节点。创建节点关联时才给涉及的节点分配可选 `nodeId`，连线与标识通过同一事务写入；布局更新时根据节点位置重算，删除节点或图形时将相连端点转为自由位置，避免静默丢失连线。静态 SVG 使用导出布局中的节点位置，隐藏节点回退到保存的端点坐标。图形拖动时按动画帧更新连线预览；指针取消、文档替换和销毁会丢弃未完成的端点草稿，连线文字使用受文档版本保护的输入草稿。旧版可能不识别节点标识，折叠和复杂连接规则尚待对照。

同级多节点概要保存为首项的 `summary` 和可选 `summarySpan`；跨度必须落在同一父节点的连续子项中，交叉跨度或无效数据保留原值并停止编辑。组内插入和删除调整跨度；删除首项时把概要转给后续项，后续项已有概要则保留原文并提示冲突。折叠首项时共同概要仍可见，折叠计数只计算隐藏项。横向、竖向、树形、时间轴及双侧同侧分支的编辑视图与静态 SVG 按组内可见节点计算概要括号，概要不占用同级节点的排版空间；双侧分界避开已有概要组，跨两侧选区不能创建概要。复杂嵌套组合仍待完善，旧版可能不识别新增字段。

Shift 选择的连续同级节点可批量设置局部结构、分支样式、文字样式与标记；每次操作对整组提交一个历史事务。若所选范围已越界则退出多选，避免变更其他节点；不同节点的其他标记与样式保留。

画布与导图共用连线端点标记及几何计算，导图面板使用同一几何绘制预览；新增标记随连线数据保存并进入撤销历史。未知标记继续保留并限制编辑，旧版可能无法识别新增值。

仅在绘制、选中或已有节点关联时测量导图节点；无节点关联的普通编辑不遍历节点计算连线位置。节点引用和图形标识查找使用集合，避免逐个交叉扫描。未就此进行性能基准测试。

导图适应画布时，合并树布局、画布文字、旋转图形、笔迹和连线的可见边界，再计算视图缩放与平移；缩放仍限制在 20% 至 100%，极远的内容可能无法全部放入视野。这些操作不修改文档。

附件仍使用原行内节点和四项文件属性；`features/media/attachment/` 中 `presentation.ts` 校验并保留显示模式和高度，`view.ts` 装配标题/卡片/嵌入及定位工具，`preview.ts` 解析同步宿主阅读地址，`embedded.ts` 管理阅读页，`resize.ts` 管理单次高度手势，`guard.ts` 与 `runtime.ts` 处理提交和实例归属。新 `displayMode`、`previewHeight` 默认 null，旧内容显示标题；`allowDownload` 默认 null，旧附件维持原下载入口，显式 false 时只读视图隐藏入口。公开 JSON 快照不写缺省下载设置；新增 JSON 属性可能被旧版严格 schema 拒绝。未知可保存显示设置原样保留且不可误编辑，损坏或冲突标记拒绝读取。阅读地址和错误不进入内容，下载保留原文件地址。独立预览与嵌入均在宿主回调后重新核对文档、视图、位置、节点值及绑定代次，处理同步重入和 ABA；集成协调先移除旧附件页，再通知其他可能抛错的能力。iframe 始终使用不透明源沙箱，原始 PDF/Office 地址明确回退到新页面。模式、高度和下载设置提交通过历史边界隔离，原节点选中时保持 NodeSelection，其他选区按事务映射。转换引擎、真实上传和服务端权限由应用提供。

音视频节点保留原有 JSON 属性和原生 HTML 媒体标记；`audio-video/audio-view.ts` 与 `video-view.ts` 管理编辑器内的播放界面和视图状态。音频可另存阅读界面的下载设置，旧内容缺省值不写入公开快照；该设置不提供服务端访问控制。换源或外部替换时释放旧媒体元素，播放 Promise 和媒体事件须核对实例、节点与代次；只读仍可播放，播放设置不写入文档。视频全屏和画中画使用浏览器能力，失败通过播放器提示。

画布的有限图形目录位于 `shape-catalog.ts`，57 个新增图形值的轮廓在 `shape-library.ts` 供绘制、命中、连线和静态 SVG 共用；`smart-templates.ts` 通过原有 shapes/groups 创建四种可编辑组合，不增加模板私有格式。`shape-picker.ts` 将五类 93 个入口展示为连续图标区，分类按钮滚动定位；图标副本单独收紧 viewBox，不能改变正式 SVG 的画布取景。浮层与文档监听仅在面板打开时存在，随重画、只读、卸载和销毁释放。

React 适配器在浏览器布局 effect 中同步受控内容，SSR 使用普通 effect；不跳过首次同步。宿主提交阶段撤销或更新内容不会被旧的被动 effect 回写覆盖，真正外部更新仍通过同一核心替换路径。适配器不维护第二份文档或旧快照黑名单。

大表测量、复现入口和窗口渲染约束见[数据表性能边界](database-performance.md)；PlantUML 的全局状态、Worker 隔离试验及未闭合的兼容问题见[PlantUML 隔离边界](plantuml-isolation.md)。

## 样式和测试

`styles/bundle.css` 是组件包和体验页共用的有序样式清单，`styles/style.css` 继续维护其中的基础样式顺序。`styles/katex.css` 是官方 KaTeX 样式的受控副本，将公式计数器限制在编辑器内；更新 KaTeX 时需同步副本并通过 CSSOM 回归检查。`packages/core/scripts/copy-style.ts` 按清单拼接样式，并将公式字体路径改写为包内路径；`demo/editor.css` 直接引用同一清单。调整样式时应保留级联、字体和许可证，并比较构建产物。

测试按功能、工具栏、生命周期和适配器归组。共享 fixture 按用途存放在 `tests/fixtures/`，专项配置位于 `tests/config/`；`tests/browser/cases/` 存放 `browser-*.ts` 场景，由 `tests/browser/browser-regressions.ts` 发现并分配给四个测试文件。`tests/browser/checks/` 中的独立浏览器检查由 `standalone-checks.test.ts` 纳入标准测试，并在临时目录构建所需的画布 fixture。静态资源的源文件放在 `tests/fixtures/assets/`，构建后仍使用原来的浏览器访问路径。移动场景或 fixture 时，须同步检查发现规则、类型配置、构建入口及静态资源路径，确认测试集合没有减少。

常见源码夹具的开发服务器和内联脚本构建分别复用 `tests/fixtures/browser/fixture-rsbuild.ts` 和 `fixture-bundle.ts`；测试负责各自的启动时机、服务关闭和临时目录清理。有特殊构建配置的测试仍可自行配置。

无需浏览器的状态和输入策略用例使用 `*.unit.test.ts`，可通过 `mise exec -- pnpm exec rstest run --config tests/config/unit-rstest.config.ts` 独立运行，避免载入浏览器配置及全局服务初始化；标准测试发现规则仍包含这些用例。模拟几何和故障回放用于验证状态安全，不能代替真实浏览器的视觉行、原生选区同步及输入法验收。

HTML 粘贴规则的离线用例使用测试工作区的 Happy DOM 和实际 ProseMirror 解析、状态及历史模块；不启动浏览器或访问网页。此类用例能检查所给 HTML 的结构和状态变化，不能证明系统剪贴板、浏览器输入及语雀私有格式的兼容性。

参数化测试优先覆盖独立行为、已观察场景和有风险的参数交叉，避免对无特殊分支的参数做全量笛卡尔组合；选区、撤销、受控回写和生命周期等边界仍需按影响保留。运行 `--related` 等依赖关系筛选时，需检查运行时启动的浏览器 fixture 是否被识别，必要时显式指定测试文件；筛选结果不能代替完整回归。

CI 将完整回归分成八片，每片使用两个 worker；手动运行 CI 时可选择 `profile`，为各片收集 Rstest 耗时追踪和摘要。常规运行不启用追踪，避免增加采集开销。

## 命名与注释

目录和普通文件使用小写 kebab-case；测试使用现有的 `.test.ts` 后缀。类型、接口、类和扩展使用 PascalCase，函数、方法和变量使用 camelCase。创建、挂载、打开、解析和归一化分别使用 `create`、`mount`、`open`、`parse` 和 `normalize` 等准确表达行为的动词。

新写或实质修改的注释以简体中文说明原因和约束，重点记录兼容格式、资源所有权、异常、重入和异步失效；不逐行复述代码。已有准确的英文注释不必仅为统一语言而改写。包名、公开导出、节点名、文档属性、CSS 类、事件、PluginKey 和存储键不能因内部命名调整而改变。
