# Issue #21：复制、粘贴与撤销的样本记录

2026-11-09 使用内置浏览器分别操作语雀隔离文档和本地 Semlo；这里只记录实际观察的路径，不代表完整剪贴板格式兼容。

- 将 `首行\n\n中行\n\n末行` 作为纯文本粘贴，两边都形成五个段落，包含两个空段，并可撤销和重做。
- 粘贴包含正文、粗体、链接、三级标题和斜体的外部 HTML，两边保留所列文字和格式；剪切粗体文字、粘到末段后，分别撤销粘贴和剪切可恢复原内容。
- 复制 H3 的文字并粘贴，所测两边均保留 H3；剪切复制出的标题文字后保留空 H3，一次撤销恢复文字。两边按下箭头后新标题的插入位置不同，这里只确认各自操作得到的标题和剪切结果，不认定导航位置相同。
- 从正文末尾跨选至紧邻的单段引用末尾并复制：语雀可见 HTML 包含前缀空段和引用。粘到空段时合并首个空段；连续两个前缀空段时保留一个。粘到正文段首、段中或替换段内选区时，目标文字前后缀留在引用之外；替换整段时不额外保留首个空段。修复后的 Semlo 用相同来源的标准 `text/html` / `text/plain` 重放所测样本，结构一致；原样本由真实复制产生，未读取或依赖语雀私有载荷。

语雀测试内容已清空，保存后重载为最新版本及 0 字，原文档标题保留。用户的其他文档和附件未参与测试。

引用专项包括结构、格式、撤销重做、受控回写、HTML/JSON 往返、多实例隔离和复杂内容的保守回退；React、Vue、Solid 的 HTML 受控回写及撤销重做各通过一项。浏览器自动化回归使用剪贴板事件复现，内置浏览器另用真实系统剪贴板检查。完整回归未运行。

所测粘贴后继续输入，语雀把新输入和原后缀放在不同段落，Semlo 当前放在同一段；两者均能分别撤销输入和粘贴。向空段粘贴后继续输入，语雀在引用后新建正文，Semlo 当前把文字追加在引用内。另在段中开启粗体后粘贴，语雀给引用文字应用粗体，Semlo 当前不继承此活动格式。上述差异尚未处理，Issue #21 不因本次修复关闭。

历史处理优先交由宿主或其他粘贴处理器决定；有后置处理器或自定义片段时回退到原流程。段尾粘贴及后置处理器返回未接管时，离线模型发现后续输入可能与粘贴一起撤销；对应语雀及实际宿主组合尚未对照。

Word、WPS、飞书、Notion 等应用的实际剪贴板、移动端、其他浏览器、真实输入法、复杂引用及更多跨块选区尚未对照；上述结果不能外推到这些来源或所有连续输入节奏。
