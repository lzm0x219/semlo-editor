# Issue #23：文字格式、链接和格式刷

## 本轮对照与修复

2026-11-09，从 `origin/main` 的 `3cf38f6` 建立独立 worktree。通过内置浏览器新建专用文档 `kdgdfl9ekpm9fo2v`，标题为“Semlo Issue 23 文字格式隔离测试”。没有操作 `zn33898gfg4s2yco`、`me65n7i0iqaymboo`，也没有修改包含用户 PDF 的 `wldgg1nmoax15d23`。

在语雀输入三个正文段落：`甲乙`、`丙丁`、`后文保留`。从第一段的 `乙` 选至第二段的 `丙` 时，更多面板中的链接按钮禁用，`⌘K` 不打开表单；只选第一段的 `甲乙` 时可打开表单并设置 `https://example.com/`。这是本轮确认的跨段落边界，不据此推断全部卡片、嵌套结构或软换行策略。

Semlo 原有 `getLinkState` 只检查编辑权限，链接会话也接受跨块范围；修改显示文字时可能将选中的段落合并。本轮把同一文本块的范围检查用于按钮状态和会话创建，跨块时保留内容、选区和历史。既有跨块链接内容仍可读取、保存，也可分别编辑其中一个文本块内的链接；没有内容迁移。

另在语雀将第一段链接文字同时设置粗体、斜体和下划线，再选择 `甲乙` 至第二段首字 `丙` 并清除格式：三种文字格式消失，链接节点、三个段落和后文保留；一次撤销恢复三种格式及原选区。Semlo 既有清除格式回归覆盖相应保留原则，本轮没有修改该实现。
