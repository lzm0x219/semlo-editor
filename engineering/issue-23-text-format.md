## 格式刷续轮对照与修复

在同一专用语雀文档输入粗体正文 `SOURCE`，以及无序项 `PARENT` 下的二级子项 `TARGET`、`CHILD KEEP`，后接同级项 `TAIL` 和正文 `KEEP`。用来源正文格式刷点击 `TARGET`，语雀将它变为粗体正文，移除列表符号；`CHILD KEEP` 仍为二级无序项，`PARENT`、`TAIL` 及后文保留。Semlo 原先只刷文字及段落属性、保留目标的列表身份，形成可复现差异。

现在，对根级两层纯无序列表中的二级叶项，正文格式刷可在同一事务内将目标转为正文，并将两侧成员展平为携带原视觉缩进的列表。只在相关列表/项的属性、内容和缩进均可保留时走这一路径；不触及旧内容的读取或无关编辑，不引入新字段。更深子树、混合有序列表、折叠或其他非默认列表属性继续沿用原有保护路径，不推测结构转换。

新增首、中、末三种位置的用例均先复现“目标仍位于列表中”，修复后格式刷专题 79/79 通过，包含保留邻项的链接和斜体、容器与编号旧路径、内容及缩进、HTML 受控回写、光标和一次撤销重做；额外子树及混合有序结构不展平。首轮修复后仍有 3 项测试因纯文本输出的空行数量随结构变化而失败，核对文字顺序与节点后将该项断言改为忽略连续空行，其余内容、格式、结构和历史断言保留。React、Vue、Solid 受控回写与撤销定向 3/3 通过，覆盖核心包入口及 JSON/HTML 回写。内置浏览器的 Vue 体验页与语雀相同样本一致，真实快捷键撤销与重做恢复前后结构。语雀正文已清空，重新加载确认空正文、0 字。

另外两组语雀观察均与现有实现一致，未改生产代码：行内代码来源刷向斜体正文，只清掉斜体而不将目标变为代码；H3 来源拖选目标正文的前三个字，目标仍为正文，所测默认字号未写成显式标题字号。此处只记录具体样本，不推断所有混合样式。

继续补查连续应用：语雀双击格式刷后点击 `TARGET` 与 `CHILD KEEP`，两项依次变为正文。Semlo 初版转换后，第二项已是平铺缩进成员，仍被旧保护挡住；新增连续应用用例先复现第二项未转为正文，再将同一规划扩展到属性可保留的纯平铺无序列表成员。每次刷选仍有独立撤销边界，连续两次撤销和重做逐步恢复对应结构；更深或混合子树不展平。最终格式刷专题 80/80、三框架定向 3/3 通过，核心构建、相关类型、代码和格式检查通过；这里因连续路径修改重跑受影响专题，没有重跑全量回归。补查结束后再次清空语雀测试正文并重载确认 0 字。

### 新建链接的默认颜色

语雀在同一段内，将一部分文字设为粗体、斜体、下划线、删除线、24px、背景色和红色，另一部分保持普通文字；选择两部分新建链接，打开表单时已移除显式前景色，其他样式保留。渐变色样本也在新建占位时移除渐变。此前 Semlo 保留颜色，会遮盖链接默认色。

修复仅发生在新建占位事务：去掉 `textStyle` 的 `color` 与 `semloEditorGradient`，保留字号、其他属性及其他 mark；不修改读取路径。编辑已有链接保留其自定义颜色。4 个新增主工具栏/API、纯色/渐变用例先失败后通过，检查占位和确认的两步撤销/重做。链接命令最终 29/29，链接格式、占位和混合格式专题 13/13 通过；既有颜色编辑用例仍检查用户对已有链接重新着色后修改文字、地址及撤销保留颜色。

### 组合输入快捷键
