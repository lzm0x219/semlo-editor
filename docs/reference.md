## 当前网页版

2026-11-03，在用户提供的空白测试文档中观察了语雀网页版普通知识库文档的编辑区，并输入测试内容核对交互。语雀会自动保存测试输入；没有点击“更新”发布。此前也观察了网页版小记编辑器，它与普通文档的菜单项目及提及范围有所不同。

当前普通文档的插入面板按基础、智能专区、画板类、数据表、程序员专区、布局和样式、小工具、嵌入本地文件、嵌入第三方服务等分组；使用过的功能可出现在“最近使用”中。空行输入 `/` 后，上方快捷项包括正文、六级标题、列表、待办、链接和代码块。链接弹窗包含“文本”和“链接”字段。提及面板默认同时显示人物和内容，并可按类型筛选；也有今天、下周和自定义日期。日期卡片提供日期选择、今天/明天/+7 天快捷项和可选时刻，时刻列表以 15 分钟为间隔。工具栏提供缩进和行高调整；在列表中，缩进会改变整个列表项的层级。

在同一空白测试文档中输入并移除了临时标题，观察到标题左侧可折叠其后内容，右侧大纲按标题层级显示并可分别折叠层级；点击大纲中被正文折叠隐藏的标题会展开其祖先并跳转。测试文字已清除并确认自动保存，未发布。

再次使用空白测试文档观察到：正文块左侧六点柄可拖动排序，一次撤销恢复顺序；点击后提供转换、删除、复制、剪切、缩进和在下方添加。格式刷单击后应用一次，双击后可连续应用，按 `Esc` 退出；普通格式可清除目标的粗体。字号快捷键按菜单档位变化，混合字号选区按起始字号计算并统一应用。测试文字已清除并自动保存，未发布。

编号标题的块操作菜单有“复制”，点击后语雀显示“复制成功”；本次浏览器自动化读取到的仍是先前的剪贴板内容，随后粘贴也得到先前内容，因此不能据此判断块复制的数据格式或粘贴后的标题编号。测试文档的标题和正文均已清空，自动保存并重新加载确认 0 字，未发布。

语雀右侧大纲中，所测编号标题的条目也显示编号，例如 `1. 准备事项`、`a. 整理清单`；Semlo 已补充大纲条目的编号并在预览页核对了显示，其他样式和边界仍需继续对照。

鼠标打开编号设置后焦点仍在正文；所测左方向键和 `Esc` 不关闭面板，再次点击编号仍显示面板，继续输入正文也保持面板打开；点击正文则关闭面板。

所测六级编号标题依次使用 `1.`、`a.`、`ⅰ.`、`1.`、`a.`、`ⅰ.` 标记；当文档只有编号 H1 与 H3 时 H3 显示 `a.`，再添加编号 H2，先前 H3 即变为 `ⅰ.`，移除 H2 编号后恢复 `a.`。全选三项无序列表并转为 H3 时得到连续编号 `1.`、`2.`、`3.`。嵌套无序列表中，将父项或其中一个二级子项转为标题后，其余二级列表项在所测场景仍保留缩进。

在上述子项转标题的例子中，把原父列表项拖到剩余子项之后，剩余子项没有跟随；移动后的父列表项显示为二级空心圆。这只记录了这一种拖动，不能推断所有嵌套列表的行为。

Semlo 的对应隔离浏览器回归起初显示父项仍为一级实心圆；修复后，所测拖动顺序及父项二级空心圆与上述语雀场景一致，撤销和重做也通过回归。

继续操作三层无序列表：一级“祖父”下有二级“父项”和“父同级”，父项下有三级“孙项”。将父项转为 H3 后，语雀依次显示一级祖父、编号 H3 父项、三级孙项和二级父同级；祖父的列表折叠入口隐藏。一次撤销恢复原列表，一次重做恢复转换结果。改为转换孙项时，祖父、父项和父同级仍按各自层级显示。选中祖父与父项的完整文字后转 H3，语雀将两项分别转为连续编号标题 `1.`、`2.`，保留孙项与父同级的原有缩进，转换后选区仍覆盖这两项文字。修复前，Semlo 已能转换所测孙项，但中间父项及祖父、父项跨层选区在本地预览均未发生转换；修复后的隔离浏览器回归已覆盖这些转换和撤销重做。

在另一份列表隔离测试文档中，对多级数字有序列表的展开或折叠父项使用块菜单转正文：父项及子项一起变为无编号正文，子项保留一级缩进，未选同级重新编号，光标落在父项行首，一次撤销恢复列表。所测父项的粗体和子项的斜体保留；其他文字格式和额外段落缩进尚未逐项核对。
