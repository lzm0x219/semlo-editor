# 功能与限制

各专题的操作和限制见[文本与文档结构](/text-and-blocks)、[表格与数据表](/tables-and-databases)、[图片、图册与嵌入](/media-and-embeds)和[公式、绘图与内容卡片](/rich-content)。

开发过程中的语雀网页操作记录和功能差异见[语雀编辑器功能对照](/yuque-feature-matrix)。

## 支持的功能

- 一至六级标题、段落、粗体、斜体、下划线、删除线、上标、下标、字号、文本颜色、高亮、对齐和链接；选中文字时提供浮动工具条。标题可折叠下属内容，右侧大纲支持层级折叠和跳转。工具栏提供格式刷、本机字体、段落缩进和行高选择，链接支持编辑显示文本与地址。
- 文字和背景色支持标准色、自定义 RGBA 和最近使用颜色，文字还支持渐变。窄工具栏通过“更多”显示末尾操作；查找支持跨文字格式及数据表当前视图的记录匹配，替换只修改正文，支持撤销。
- 无序列表、有序列表、待办、引用、代码块、分割线、图片、折叠块和高亮块；表格支持尺寸选择、右键批量操作、合并拆分单元格、序号列，以及通过边缘色带选择和拖动行列。表格工具栏提供列等宽、自适应、最大化、边框和标题行列设置。代码块支持名称、语言搜索、六种主题、字号与缩进设置、语言感知缩进、换行、行号、全文样式同步、标题栏隐藏与逐块恢复、折叠和复制；部分语言使用纯文本或近似规则。图片可与文字同段排列，支持旋转、裁剪、尺寸、样式、描述、链接、对齐、复制、删除和预览。
- 数据表提供独立的结构化记录，支持编辑列与记录、筛选、排序、分组和统计，以及共享记录的表格、画册、看板、日历和图表视图。看板支持鼠标拖动卡片；日历支持拖动日程及调整起止日期、农历与节气显示。图表看板支持柱状图、条形图、面积图、折线图、饼图、漏斗图、散点图、热力图、统计数字和词云，可配置数据、筛选及部分样式。调整图表大小时，画布按网格自动安排卡片。数据随文档的 JSON / HTML 保存。
- 图册支持多图上传、轮播、缩略图轮播和平铺，以及图片排序、标题与链接设置、预览和撤销。
- 状态标签、行内和块级 TeX 公式、可调整宽度的两至四栏布局、带可选时刻的日期标签、中文搜索表情和月视图日历。跨周日程按周分段，可拖动日程或调整结束日期；日程保存在文档数据中。公式使用 KaTeX 渲染；样式和公式字体随构建产物提供。
- 文本绘图支持 PlantUML、Mermaid、Flowchart 和 Graphviz，提供模板、实时预览、高度调整与最大化，并在浏览器本地渲染。
- 提供画板、思维导图、流程图和 UML 图等基础绘制入口；图形库和交互仍需继续验证。
- 提及人物或文档；候选项由接入方的 `searchMentions` 提供。日期快捷项可从提及菜单插入。
- 附件、本地视频和本地音频通过上传回调插入；音视频使用浏览器原生播放器。
- 支持将哔哩哔哩、CodePen、Figma 等指定服务的链接插入为第三方嵌入卡片，并可转换回普通链接；加载受第三方服务和权限限制。
- 基础 Markdown 输入快捷方式、行首 `/`、工具栏插入按钮和 `⌘/Ctrl + /` 卡片菜单，以及撤销与重做。插入菜单提供最近使用项。
- 正文块左侧的操作柄支持拖动排序、类型转换、删除、复制、剪切、缩进和在下方插入；列表项可跨列表移动，普通块可将列表拆开，表格和复杂卡片作为整体操作。
- JSON 和 HTML 内容输入；变更事件同时提供 JSON、HTML 和纯文本。
- 只读模式、自定义扩展、图片和附件上传回调，以及独立的样式文件。

这里的 Markdown 快捷方式指输入时的格式转换，并非完整的 Markdown 导入和导出。上传服务和提及搜索需要由接入方提供；配置图片上传回调后可从按钮、剪贴板或拖拽插入图片，附件与音视频通过插入面板选择文件。

## 当前边界

本组件使用 KaTeX、lunar-typescript 和 Material Design Icons，其许可证分别随构建产物的 `dist/KATEX-LICENSE.txt`、`dist/LUNAR-TYPESCRIPT-LICENSE.txt` 与 `dist/MATERIAL-ICONS-LICENSE.txt` 附带。

这是持续开发中的实现，不宣称与语雀功能或数据格式完全兼容。尚无 Lake 格式兼容、文档持久化、多人协作、评论、AI 助手、完整 Markdown 导入导出或独立的无障碍审计；第三方嵌入仅支持指定服务与地址格式。数据表的人员搜索、图片和附件上传以及创建人和修改人信息依赖接入方提供对应能力；图表尚不提供拖动换位。字段转换与快捷键等行为仍需继续对照。图表的静态 HTML 保存配置和记录，独立展示时以表格形式呈现。编辑器内的有序列表会按层级重新计算编号，导出的 HTML 包含相应的列表项序号。块级公式是本项目的扩展，尚未逐项对照当前语雀行为。音视频可播放的格式取决于浏览器和返回地址；语雀的在线文件预览服务未实现。真实本机字体授权、上传与提及服务、中文输入法、跨浏览器、长文档、复杂粘贴和当前语雀的完整交互仍需实测。
