# 公式、绘图与内容卡片

通过工具栏插入按钮或插入菜单选择内容类型。插入后在卡片中编辑；大多数卡片作为一个正文块参与块操作。

## 公式

支持行内和块级 TeX 公式，由 KaTeX 渲染。例如可输入：

```tex
E = mc^2
```

编辑时，公式在正文和面板中实时预览。点击“确定”、按 Escape 或使用 ⌘ / Ctrl + Enter 会提交当前源码；点击公式和面板以外的区域也会提交。编辑面板打开期间的内容尚未写入文档，刷新页面会丢失未提交的修改。

公式源码随文档保存。导出的 HTML 保留 TeX 源码和标记，重新载入编辑器时渲染；在编辑器之外展示时，需要接入方自行处理公式渲染。块级公式是 semlo-editor 的扩展，尚未逐项对照语雀行为。

## 文本绘图

文本绘图支持 PlantUML、Mermaid、Flowchart 和 Graphviz，其中 Mermaid 由 Pele 渲染。选择语言后输入源码或使用内置模板，可在浏览器本地预览；卡片支持调整高度、最大化以及切换预览。切换语言保留源码，选择模板会替换源码。

例如，在 Mermaid 模式下输入：

```text
flowchart LR
  A[开始] --> B[完成]
```

源码和设置随 JSON / HTML 保存。静态导出保留源码，但不会自动生成图形；外部 include、主题资源与图片暂不加载。

PlantUML 引擎依赖页面的主线程和全局状态。若页面已使用同名引擎状态，编辑器会提示无法安全渲染；需要与宿主的绘图引擎隔离。当前保护不能隔离渲染期间后来启动的宿主代码，若引擎一直不返回，后续 PlantUML 绘图也可能等待。

## 画板与图形

插入菜单还提供画板、思维导图、流程图和 UML 图入口。画板、流程图及 UML 图共用画布能力，思维导图使用独立编辑视图。图形数据随文档保存，静态 HTML 包含 SVG 图形。

思维导图可添加、编辑和折叠节点；选中中心节点后，可在“结构”中切换向右、向左、双侧、向上、向下、四种树形及两个时间轴布局。布局随 JSON / HTML 保存并可撤销，静态 SVG 也使用所选布局。旧导图缺省为向右布局；复杂结构和画布工具尚未完整对照。较早版本可能无法保留新增的布局属性，混用版本保存前需验证。

选中非中心节点后，可单独将该子树设为分支、向下树形、向上树形或时间轴；其他分支保留各自的结构。设置随导图保存并可撤销，静态 SVG 包含混合布局；复杂嵌套组合仍需对照，较早版本可能无法保留新增设置。

导图可最大化编辑并返回文档，最大化界面提供撤销和重做；“适应画布”会同时考虑节点、画布文字、图形、笔迹和连线，最低缩放比例为 20%。缩放、平移和最大化状态属于当前视图，不写入文档。

画布工具提供画笔、马克笔和橡皮擦，可设置笔触粗细与颜色；橡皮擦按整笔擦除，绘制和擦除支持撤销。笔迹随 JSON / HTML 保存，只读视图及静态 SVG 显示笔迹。较早版本可能无法保留新增笔迹数据；其他画布工具仍在完善。

画布文字工具可在任意位置创建独立文字，双击编辑，拖动或使用方向键移动、旋转，并用四角手柄调整文字框宽高；调整框体不改变字号。文字支持水平及垂直对齐、字号、颜色、加粗和部分文字链接，删除与修改支持撤销。设置随 JSON / HTML 保存，并包含在静态 SVG 中；不支持 SVG 内 HTML 的消费器会回退为按显式换行绘制的文字，自动折行和特殊字体可能有差异。较早版本可能无法保留新增文字数据或链接。

图形工具提供基础图形、流程图、Smart、UML 和 ER 的 93 个目录入口，可点击画布放置，双击编辑文字，拖动移动、调整大小或旋转，并设置填充和描边；修改支持撤销，图形随 JSON / HTML 和静态 SVG 保存。四种 Smart 模板可整体移动、缩放、旋转和取消编组，旋转后的组合按比例缩放；复杂编组等操作仍在完善，较早版本可能无法保留新增数据。

连线工具可拖出直线、曲线或折线，调整端点、起点和终点箭头、线型、颜色、粗细和文字，也可交换连线方向。端点可吸附导图节点或画布图形并跟随位置变化；删除节点或图形后连线保留，端点变为自由位置。连线随 JSON / HTML 和静态 SVG 保存并可撤销。起点与终点各提供 21 种标记和无标记选项，包括单侧线、圆圈及三叉线组合；具体外观和折叠节点的连线行为仍待进一步对照。较早版本可能无法识别新增的节点标识或标记样式。

选中节点后可设置粗体、斜体、删除线、下划线、字号、文字颜色和对齐方式；设置随导图保存并可撤销，静态 SVG 保留样式。旧版编辑器可能无法识别新增的节点样式，混用版本前需验证。

导图颜色面板提供主题色、默认色、色彩梯度和自定义颜色，用于文字、分支、节点填充及描边。

分支支持曲线与直角线型；选中非中心节点后，还可设置该分支的颜色和 1–5 像素粗细。设置随导图保存，子分支默认继承上级颜色；静态 SVG 保留线型与颜色。旧版编辑器可能无法识别新增的分支样式。

节点支持横线、矩形和圆角形状，矩形及圆角节点可设置填充、描边颜色和描边粗细，也可设为透明。外观随导图保存，静态 SVG 保留设置；旧版编辑器可能无法识别新增字段。

节点可同时添加优先级、进度和旗帜标记；点击已有标记可更换或清除，标记随导图保存，静态 SVG 包含对应图形。旧版编辑器可能无法识别新增字段。

非中心节点可添加一个概要，概要可编辑文字、添加下级节点，并随导图保存和撤销。先点击一个节点，再按住 Shift 点击另一同级节点，可批量设置连续范围的结构、分支样式、文字样式和标记；横向、竖向、树形、时间轴以及双侧布局的同侧分支可为该范围添加共同概要。组内插入或删除节点时，概要范围随之调整；删除首项时若后续节点已有概要，会提示先处理冲突。双侧布局增删节点时，属于同一概要的分支保持在同一侧；跨两侧范围暂不能添加共同概要。折叠首项的子节点不会隐藏共同概要。交叉概要和复杂排布仍待完善，旧版编辑器可能无法识别新增字段。

节点可设置链接文本和地址、打开或移除链接；双击节点并选中部分文字后，可以为不同文字分别添加链接。编辑文字时链接范围随之调整，只读视图和静态 SVG 保留可点击链接。较早版本可能无法识别带链接的节点；复杂编辑组合和输入法行为仍待核验。

画布右上角可缩放、适应画布及切换平移；平移模式下可拖动，键盘聚焦画布后也可使用方向键。缩放和平移仅作用于当前视图，不写入文档。

画板、流程图和 UML 图的左侧工具栏提供选择、画笔、橡皮、文本、图形、连线和图片；平移位于画布右上角。“更多形状”按基础图形、流程图、Smart、UML 和 ER 五类组织当前已核对的 93 个入口，矩形等基础图形也从此面板选择；分类按钮定位到连续排列的图标区，支持方向键、Enter、Esc 和触摸。选择图形后点击画布放置，UML 的“角色”提供参与者图形。编辑和 SVG 导出共用相同轮廓，图形沿用文字编辑、移动、缩放、旋转、删除和撤销。

Smart 提供金字塔、分段金字塔、阶段图和架构图，按点击位置创建组合；可整体变换，也可取消组合后分别编辑图形与文字，一次撤销可恢复创建前内容。这些是当前核对的有限图形和模板，不表示支持完整 UML / ER 建模语义或语雀全部图形。

画布的类型、图形、高度或视口数据无法识别时，编辑器保留原始值并提示暂不可编辑，避免将它们按默认值覆盖。新增图形值可能无法在旧版本编辑；较早版本也可能无法保留新版 HTML 中的原始展示信息，混用版本保存时需另行验证。

## 智能写作助手

应用配置 `writingService` 后，可从插入菜单、斜杠、块下方或选区入口打开写作助手，输入提问并生成草稿。等待时可停止，失败可重试；检查预览后再明确插入或替换选中文字。提示和草稿不进入文档快照，接纳可一次撤销。服务契约、动态更新和目标失效规则见[智能写作助手](/writing-assistant)。

## 代码块与分栏

代码块支持名称、语言搜索、六种主题、折叠和复制。更多设置中可以调整字号、缩进模式与宽度、自动换行和行号，也可以将样式或样式与语言同步到全文。选中多行后使用 Tab 和 Shift+Tab 缩进；未选中文本时 Tab 插入制表符。回车按当前语言的缩进规则处理；“自动缩进”命令重新整理整个代码块的行首缩进，保留选区，可一次撤销。新建代码块继承同一编辑器实例最近使用的设置；重新加载或更换实例后暂不共享。

更多设置还可以隐藏当前展开的代码块标题栏，聚焦后点击顶部小柄可逐块恢复；新建和已折叠的代码块仍显示标题。隐藏状态保存在 semlo-editor 的 JSON / HTML 内容中，隐藏与恢复不加入文字撤销历史。

语言菜单标明高亮范围：ABAP、Agda、ArkTS、Asm、Basic、Cypher、Git、GraphQL、JSX、KaTeX、Makefile、Markdown、PL/SQL、Sass、Shell、Solidity、sTeX、SystemVerilog、TSX、Velocity 和 Vue 使用近似语法高亮。缩进解析另有独立语言支持；ABAP、Agda、Basic、Git、GraphQL 和 Makefile 暂按纯文本规则处理，Solidity 使用近似缩进解析，其余部分语言也采用近似解析。过长代码无法及时完成解析时，自动缩进会提示未完成并保留原文。代码运行由接入方提供 `runCode` 回调，编辑器不自行执行代码；输出与运行环境由宿主负责。

分栏支持两至四栏，并可拖动分隔线调整宽度。插入分栏后，在各栏中分别编辑内容。

## 日期、状态和日历

日期标签可选择日期和可选时刻；按本地日期、小时和分钟保存，不附带时区，也不进行时区换算。状态标签可编辑文字与颜色。高亮块提供配色，折叠块包含标题和正文；查找命中折叠正文时会展开，展开与替换可以分别撤销。

月视图日历支持带日期、颜色和说明的日程，日程保存在文档数据中。跨周日程按周分段，重叠日程分行显示；拖动日程可整体移动日期，拖动最后一段右端可调整结束日期。这些操作支持撤销。表情支持中文搜索。提及人物和文档需要应用提供搜索回调，详见[上传与提及](/uploads-and-mentions)。
