# 语雀编辑器功能对照

这份清单记录 semlo-editor 开发过程中的功能对照。本表是历史开发记录，不代表当前产品状态或最终产品定位。语雀侧只记录团队在用户提供的测试文档中实际操作过的行为，以及亲眼看到的界面入口；没有根据资料补充功能。范围是 **2026 年 11 月 3 日至 4 日当前账户下的语雀网页版普通知识库文档编辑页**，不代表小记、其他客户端、其他账户权限或之后的产品版本。

按最新范围整理的功能状态与统计见[语雀编辑器复刻进度](/replication-progress)。

详细操作过程与测试文档恢复情况记录在项目的 `engineering/reference.md` 的「当前网页版」部分。下表中的 semlo-editor 状态和测试结果记录的是对照时的情况，可能已变化；当前能力与限制见[功能与限制](/features)。测试通过只说明覆盖的场景正常，不能证明与语雀完全一致。这里不以功能数量计算完成百分比。

## 如何阅读

语雀观察分为三种：

- **已操作**：实际输入、点击或拖动过；只对描述的操作作结论，其他行为仍需核验。
- **仅看到入口**：在当前界面看到了菜单项或按钮，尚未对该项的效果作充分操作记录。
- **尚未验证**：当前记录不足以判断语雀是否支持或如何表现。

semlo-editor 状态分为 **已有实现**、**部分实现**、**未实现**、**不对齐（用户要求）**和 **不复刻（用户要求）**。即使标为「已有实现」，也仅表示已有所述功能；表格中的差异和待验证项仍需逐项核对。用户要求不复刻的功能不纳入复刻验收。另有项目自身的扩展，不计入语雀复刻完成度。

## 复盘顺序

2026-11-07 补充：可验证文字流的标题软换行交界已加入视觉行探测，所测上下行、编号、撤销和部分宿主边界通过；复杂混排及不可验证布局仍需处理，语雀对应行为尚未逐项对照。

2026-11-08 补充：标题折叠默认已随可编辑文档的 JSON / HTML 保存并可重载恢复；宿主仍负责实际存储，旧版读取及只读行为的边界见[保存与恢复内容](/persistence#标题折叠视图状态)。下表保留改动前的差异记录。

2026 年 11 月的复盘从正文与标题开始，按编辑、焦点、键盘、撤销、保存往返和框架接入等场景记录差异；当时正文与标题仍在复盘中。此前的浮动工具与智能写作助手排除决定已由用户于 2026-11-07 更新：两者纳入对照；多人协作、评论及 Lake 格式兼容不实现。下表保留当时的观察与未验证项，不作为当前进度清单。

| 本机字体   | **项目扩展**：自动读取并缓存本机字体，支持刷新、名称展示和定位当前项；有选区时作用于选区，否则作用于全文。首次访问可能需要浏览器授权，真实系统字体及权限组合仍需验证。                                                                                                                                                                                                                                                                                                                                                                                          |

| 内容格式   | **项目能力**：支持 JSON、HTML 输入和变更输出，以及纯文本输出；Markdown 仅有部分输入快捷方式，未实现完整 Markdown 导入导出和 Lake 数据格式兼容。                                                                                                                                                                                                                                                                                                                                                                                                                 |
