# 表格与数据表

正文表格适合排版文章中的行列内容；数据表适合维护结构化记录，并以不同视图查看同一批数据。

## 正文表格

从插入面板的表格网格选择行列数。点击单元格后可使用表格工具栏调整列宽、等宽、自适应、边框、标题行列和配色，也可最大化表格。

右键单元格或选中的单元格区域，可插入或删除行列、合并或拆分单元格、清除内容、复制或剪切；边缘色带可用于选中、插入及拖动行列。批量插入的数量上限为 100。未手改的序号列可随插行更新；手改后插行会保留已有内容，新序号格保持为空。部分合并格支持编号，无法安全处理的复杂跨度会受到保护。

在单元格内粘贴多行纯文本时，换行形成段落，制表符保留在当前单元格；HTML 表格片段可按单元格粘贴。这些操作支持撤销。复杂嵌套表格、触屏和跨浏览器交互仍需验证。

## 创建数据表

在插入菜单中选择数据表、画册或看板入口。新建数据表默认包含文本、单选和日期三列以及三条空记录；默认单选项为“待开始”“进行中”和“已完成”。

例如，维护项目任务时可以将文本列命名为“任务”，用单选列记录状态，在日期列记录日期，然后根据需要新增记录。数据表是文档中的内容：保存和恢复编辑器 JSON 或 HTML 时会保留数据与视图。

每个数据表最多支持 200 个字段、10,000 条记录和 100 个视图；每个字段最多有 200 个选项，每个文件字段的默认值或单元格最多包含 100 个文件，多选或人员值最多包含 100 项。单元格文本最多为 10,000 个 UTF-16 代码单元，字段名和选项名最多为 200 个 UTF-16 代码单元。其他配置也有各自的容量和长度限制。

超限操作会保留已有数据并在编辑器中显示错误，接入方也可通过 `onError`（Vue 为 `error`）接收。选择文件时如已超出数量限制，不会开始本次上传。导入损坏或超限的数据表时，初始化会抛出异常，`setContent()` 则报告错误并保留当前文档；恢复时应保留原始数据，处理问题后重试。数据表节点缺少有效载荷也会被拒绝。

## 字段与记录

支持文本、数字、单选、多选、人员、图片、附件、日期、复选框、链接、邮箱、手机号码、评分和进度字段，以及创建时间、修改时间、创建人和修改人自动字段。可通过列菜单编辑、复制、插入或删除列，并设置可用字段的默认值或选项。

人员候选项由 `searchMentions` 提供；图片和附件分别使用 `uploadImage` 和 `uploadAttachment`。创建人和修改人由 `currentUser` 提供，未配置或返回 `null` 时不记录用户身份。返回的用户标识和名称必须为非空字符串，长度分别不超过 500 和 200 个 UTF-16 代码单元；若返回值无效或回调抛错，相关编辑会中止并通过 `onError` 报告，原记录不变。字段类型转换可能影响值如何展示，应用在依赖转换结果前应对自己的数据进行验证。

文本列可配置 AI 智能填写，选择“内容总结”或输入自定义规则；列菜单可再次填写。填写由应用提供的 `databaseAiFill` 执行，用户主动开始时会向该回调提供整表字段、选项和记录；成功结果替换对应列，可整体撤销。尚未配置服务时仍可保存规则。接入方式、数据边界和失败处理见[内容与集成](/content-and-integrations#数据表智能填写)。语雀服务测试未返回生成结果，成功时的实际行为尚待对照。

## 筛选、排序与统计

视图可添加筛选条件，并选择条件之间的关系；可按字段排序或分组。可用筛选操作取决于字段类型，例如文本支持包含、开头、结尾及空值条件，数字支持比较。

列统计提供总数、空和非空计数；数字、评分和进度列还提供求和与平均值，数字列另支持中位数、最大值和最小值，日期列支持最早、最晚及时间范围。按语雀所测展示，空日期列的最早时间为 `Invalid Date`，空数字列的中位数为 `NaN`。视图中的筛选和排序用于展示记录，原始记录仍属于同一数据表。

## 数据表视图

同一数据表可创建表格、画册、看板、日历和图表视图，它们共享字段与记录，各视图保留自己的显示设置。画册与看板可配置字段显隐及是否显示字段名，首个可见字段作为卡片标题。看板使用单选字段分组；没有单选列时需先添加。

在看板中拖动卡片可调整该视图中的顺序；跨分组拖动会更新记录对应的单选值。拖动可撤销，表格中的原始记录顺序不会因此改变。编辑器全文查找可匹配当前视图筛选后的记录，但数据表中的匹配项不能通过全文替换修改。

日历按所选开始和结束日期字段展示记录，跨周日程按周分段显示；没有开始日期的记录不会出现在网格中。可在日历设置中选择标题字段、颜色、周起始日及农历和节气显示，也可在日期格中添加日程。拖动日程可移动日期，拖动两端可调整起止日期；只有一个日期字段时，扩展日程会新增结束日期字段。这些修改可撤销。只读模式下仍可浏览月份和查看记录。

图表视图可添加多个柱状图、条形图、面积图、折线图、饼图、漏斗图、散点图、热力图、统计数字或词云组件，并分别配置字段、筛选、排序及部分样式。组件可编辑、复制、删除和调整大小；画布使用十二列网格，并自动处理空位和卡片碰撞。图表拖动换位尚未实现。图表配置和记录随文档保存，独立展示导出的静态 HTML 时显示为表格。

当前浏览月份保存在该浏览器标签页的会话存储中，不属于文档数据或撤销历史；会话存储不可用时仅在编辑器实例内保留。农历和节气由本地历法库计算，法定调休及所有历史、未来日期尚未逐项核验。

数据表的字段模型是内部实现，并非核心入口公开的编程 API。接入方应使用[快照与内容 API](/api#数据类型)保存和恢复整个文档，避免依赖内部数据结构。
