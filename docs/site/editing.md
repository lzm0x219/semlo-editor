# 编辑与组织内容

semlo-editor 在工具栏、插入面板和正文块操作柄中提供编辑操作。以下介绍常用入口；完整能力及尚未实现的功能见[功能与限制](/features)。

## 插入内容

点击工具栏的“插入内容”，或在空行输入 `/` 打开插入菜单；也可以使用 `⌘ / Ctrl + /`。菜单可搜索内容类型，并显示最近使用的项目。

常用内容包括标题、列表、待办、引用、代码块、表格、图片、公式、分栏和高亮块。输入 Markdown 风格的快捷标记可以转换部分格式，但这不等于完整的 Markdown 导入或导出。

链接对话框可通过“取消”或 `Esc` 关闭。部分新建链接的入口会在打开时先插入未设置地址的占位；关闭对话框后占位仍保留，可通过撤销移除。已填写的地址需点击“确定”才会应用。

## 组织文章

标题支持一至六级，右侧大纲按层级显示标题并支持跳转。标题内容和大纲层级都可以折叠；点击大纲中被折叠内容隐藏的标题时，编辑器会展开其祖先并跳转。可编辑文档的标题内容折叠默认随内容保存，大纲自身的折叠属于当前界面状态。

正文块左侧的操作柄可用于拖动排序、转换类型、复制、剪切、删除、缩进和在下方插入内容。表格和复杂卡片作为整体操作。无法无损转换的类型会禁用对应转换。

## 表格和数据表

普通表格适合在正文中排版：可插入行列、合并或拆分单元格，并通过工具栏调整边框、标题行列和列宽。复杂嵌套、触屏与跨浏览器行为仍需验证。

数据表用于结构化记录：可编辑字段和记录，筛选、排序、分组或统计，并通过表格、画册、看板、日历和图表视图查看共享记录。图表支持柱状图、条形图、面积图、折线图、饼图、漏斗图、散点图、热力图、统计数字和词云；当前已观察的 18 种字段类型均有对应入口，文本列智能填写由宿主提供服务，行为与真实服务仍需核验。数据随文档 JSON 和 HTML 保存。

## 图片、图册与附件

图片可与文字同段排列、旋转、裁剪，设置尺寸、样式、描述和链接，也可复制、删除和预览；图片对齐会作用于整个段落。图册支持多图上传、排序、标题与链接，以及轮播、缩略图轮播和平铺。附件、音频和视频需要上传回调，编辑器内提供音视频播放控件，支持的格式取决于浏览器与返回地址。接入步骤见[上传与提及](/uploads-and-mentions)。

## 公式与绘图

公式支持行内和块级 TeX，在编辑器中由 KaTeX 渲染。文本绘图支持 PlantUML、Mermaid、Flowchart 和 Graphviz，可编辑源码并在浏览器本地预览。绘图静态导出保留源码，但不会自动生成图形；外部 include、主题资源和图片暂不加载。

## 查找与格式

查找替换支持跨文字格式匹配、结果导航、逐项或全部替换，以及撤销。数据表当前视图中筛选后的记录和未隐藏字段可参与查找；替换跳过数据表命中项。焦点位于数据表内时，`⌘/Ctrl + F` 打开表内搜索。选中文字可使用浮动工具条；格式刷单击应用一次，双击可连续应用，按 `Esc` 退出。

工具栏“更多”中的字体菜单读取本机字体，依赖浏览器的 Local Font Access API 和授权。文档会保存字体名称而不会携带字体文件，因此其他设备可能回退显示。更多状态和字体说明见[内容与集成](/content-and-integrations#字体与界面状态)。
