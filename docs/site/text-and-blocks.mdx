## 标题与大纲

在工具栏的正文类型菜单中选择标题，或通过插入菜单选择一至六级标题。有标题时，右侧显示大纲细线；鼠标移入或点击可展开标题树，点击条目可跳转到对应位置。大纲支持折叠分支和整体折叠，也可通过键盘打开并按 `Esc` 收起。

标题左侧的折叠控件可以收起其下属内容；从大纲跳转到被隐藏的标题时，编辑器会展开所需的祖先标题。标题折叠与大纲折叠是界面状态，不写入文档；重新挂载后展开。窄容器中大纲入口会缩窄，也可在创建时设置 `outline: false`。

## 文字与段落

选中文字后使用工具栏或浮动工具栏设置粗体、斜体、下划线、删除线、上标、下标、字号、颜色和高亮。工具栏还提供对齐、缩进和行高。文字颜色支持标准色、自定义 RGBA 和渐变；背景色支持标准色和自定义 RGBA。

格式刷单击后应用一次，双击可连续应用，`Esc` 退出。它复制文字格式，不改变段落或标题类型。来源包含混合格式时，粗体等文字样式、字号和颜色以选区起始文字为准；字体不一致时保留目标文字的字体。

字体菜单读取本机字体，需要浏览器支持 Local Font Access API，并可能要求授权。选中文字时修改选区字体；没有选中文字时修改整篇文档，并清除原有局部字体覆盖。字体名称随文档保存，字体文件不会随之嵌入；其他设备缺少字体时由浏览器回退。

## 列表、待办与块操作

插入菜单提供无序列表、有序列表和待办。列表缩进会改变列表项层级；有序列表按层级计算编号，导出 HTML 时附带对应序号。

将指针移到正文块左侧，使用块操作柄可以拖动排序，或打开菜单进行转换、删除、复制、剪切、缩进和在下方插入。列表项可跨列表移动，普通块可将列表拆开；表格和复杂卡片作为整体操作。不可无损转换的类型会禁用转换。复杂嵌套和触屏拖动仍需进一步验证。

## 链接

选中文字后通过工具栏插入链接，可编辑显示文本和地址；也可在空选区插入。支持锚点和相对地址。链接编辑涉及混合格式时，修改显示文本会保留选区起始文字的格式。

## 快捷入口

| 操作           | 快捷键或入口                                   |
| -------------- | ---------------------------------------------- |
| 打开插入菜单   | 空行输入 `/`，或按 `⌘/Ctrl + /`                |
| 插入或编辑链接 | `⌘/Ctrl + K`                                   |
| 查找替换       | `⌘/Ctrl + F`                                   |
| 调整字号       | macOS：`⌥⌘ + / -`；Windows：`Ctrl + Alt + / -` |
| 调整行高       | `⌘/Ctrl + Alt + [` 或 `]`                      |
| 退出连续格式刷 | `Esc`                                          |

字号按菜单档位变化；混合字号选区以起始文字的字号计算并统一应用。查找支持跨相邻文字格式匹配、结果导航、逐项或全部替换及撤销。基础 Markdown 输入快捷方式只负责输入时的格式转换，不能作为完整 Markdown 导入导出使用。
