## 标题与大纲

在工具栏的正文类型菜单中选择标题，或通过插入菜单选择一至六级标题。有标题时，右侧显示大纲细线；鼠标移入或点击可展开标题树，点击条目可跳转到对应位置。大纲支持折叠分支和整体折叠，也可通过键盘打开并按 `Esc` 收起。

将指针移到根级标题左侧，点击 `H1` 至 `H6` 可复制指向该标题的当前页面链接。首次复制会给标题写入标识并触发 `onChange`，应用需要保存快照；重新打开链接并加载同一文档后，编辑器会展开所需的折叠标题并滚动到目标。已有标识的标题在只读状态也可复制；只读的旧标题不会被自动改写。同文档粘贴带标识的标题时会为副本生成新标识，拆分标题也不会让两个标题共用标识。

链接使用当前页面地址及 `semlo-heading` 查询参数；接入应用需保证该地址可重新加载对应文档，或自行处理链接中的标识。标识写入 JSON 的 `semloEditorHeadingAnchor` 和 HTML 的 `data-semlo-editor-heading-anchor`；旧版严格 JSON 读取器可能拒绝新增属性，普通静态 HTML 页面也需要自行实现定位。此链接格式不代表与语雀链接兼容。

在标题中使用 `Home`、`Shift+Home` 或 `Shift+End` 时，编辑器优先使用可确认的视觉行位置。复杂排版下无法可靠定位行首或行尾时，会保持当前选区；已有选中文字仍可正常删除。手动建立的跨块选区和全文选择继续按原有规则处理。

标题左侧的折叠控件可以收起其下属内容；从大纲跳转到被隐藏的标题时，编辑器会展开所需的祖先标题。可编辑文档的折叠状态默认随内容保存，应用重新加载保存的 JSON 或 HTML 后可恢复；只读时的临时展开不会改写内容。应用也可通过 `headingFoldPreferences` 独立保存标题折叠位置，见[折叠状态持久化](/persistence#标题折叠视图状态)。窄容器中大纲入口会缩窄，也可在创建时设置 `outline: false`。

## 文字与段落

选中文字后使用主工具栏设置粗体、斜体、下划线、删除线、上标、下标、字号、颜色和高亮。工具栏还提供对齐、缩进和行高。文字颜色支持标准色、自定义 RGBA 和渐变；背景色支持标准色和自定义 RGBA。默认选区浮层提供 AI 入口，接入方式见[写作助手](/writing-assistant)；应用也可自定义浮动工具栏。

根级正文或标题使用行高快捷键时，混合选区以第一个显式行高为基准统一所选文字块；没有显式值时以默认值为基准。默认档位位于 1.5 和 2 之间，可一次撤销恢复原有值。

向默认空白正文粘贴带行高的多个正文段落时，首段行高会保留。紧接着全选并使用行高快捷键的所测操作可以一次撤销；停顿后调整会单独撤销。

“清除文字格式”移除所选文字的内置格式，保留链接及其地址、正文、块结构和段落缩进与行高。按钮与 `⌘/Ctrl + 反斜杠` 使用相同行为，可一次撤销和重做；局部选区不会扩大为整条链接。

格式刷单击后应用一次，双击可连续应用，`Esc` 退出。对根级正文、标题和简单平铺列表项，点击目标时会复制块类型、文字格式、对齐、缩进和行高，并将光标留在点击处；待办还会复制勾选状态，点击空块后输入会继承文字格式。引用、高亮块、折叠正文、分栏和表格单元格内，正文、标题及平铺无序列表、待办项也可互刷；符合条件的有序列表可接入相邻正文或转换首尾项。根级平铺编号列表已有有效续接时，可以转换其中单项，并按目标类型保持或升级续接；从编号项刷到相邻正文时，新项接入来源项所属的序列。有效非默认起点的平铺列表也支持这些操作，接入相邻旧列表时保留其起点。拖选文字时只复制文字格式并保留选区。来源包含混合格式时，粗体等文字样式、字号和颜色以选区起始文字为准；字体不一致时保留目标文字的字体。容器内有序列表中间项、不同编号样式及复杂嵌套列表的块类型转换尚未覆盖。

从旧版有序列表中间刷走一项时，为维持两侧编号联动会写入版本化序列及续接字段；旧版严格读取器可能无法读取新内容，详见项目 ADR 0002。

字体菜单位于工具栏“更多”中，可读取本机字体，需要浏览器支持 Local Font Access API，并可能要求授权。选中文字时修改选区字体；没有选中文字时修改整篇文档，并清除原有局部字体覆盖。字体名称随文档保存，字体文件不会随之嵌入；其他设备缺少字体时由浏览器回退。

## 列表、待办与块操作

插入菜单提供无序列表、有序列表和待办。列表缩进会改变列表项层级；有序列表按层级计算编号，导出 HTML 时附带对应序号。 默认混合编号的罗马层级使用 `ⅰ`、`ⅳ`、`Xⅲ` 等字形；载入显式 HTML `i/I` 时沿用原来的样式规则。

包含重新编号的有序列表，已验证的同父、同层叶项可通过块柄重排，各编号序列独立计数。首次这类重排会在同一可撤销变更中写入新版序列字段；部分旧嵌套列表的跨项纯文本粘贴也会写入这些字段。读取旧内容或普通输入不会自动迁移。

新版编号的无续接平铺列表，至少有两项时可将单项或连续多项转为待办或无序列表；中间范围包括交错编号序列，前后列表的编号仍会联动。相邻根级正文和同序列平铺列表也可同选转换，未选项保留原有编号序列。已有续接的同序列平铺片段可转换单项、连续项或整段，交错片段支持中间范围；原 v1 链会在同一次操作中升级为 v2。完整选中转换后的中间范围时，可在两侧序列和格式兼容的情况下转回有序列表；中间隔有正文或 v3 标题时保留原有间隔并接回编号。符合条件的交错中间项或续接链中间片段转为正文、标题时也保留来源，完整选中后可按原编号序列接回。受支持的正文、标题、待办和无序列表转换及拆分保留来源；单独复制间隔项会移除来源。续接链两端整段转换及其他多级结构仍有边界；自定义 HTML 属性的保留要求见项目 ADR 0002。

无序列表快捷键为 `⌘/Ctrl + Shift + 8`，待办快捷键为 `⌘/Ctrl + Alt + T`；二者与工具栏使用相同的转换规则。

默认混合编号的简单两级列表中，末尾子项与前一同层项属于同一序列时，也可转换为待办或无序项并保留缩进；转回有序列表时会接续相邻列表的同层序列。其他多级转换仍受限制。

无续接且属于同一序列的平铺列表，单个或连续列表项可通过段落样式、快捷键或块菜单转为编号标题，支持混合、中文和多级数字样式；标题优先继承已有同级标题样式，否则沿用列表样式。中间项转换后，两侧列表仍会联动续号，转换可撤销。选区也可覆盖该列表与相邻根级正文，一起转为标题；列表后的正文会继承前面生成的同级标题编号。在标题中使用有序列表入口可以切换标题编号，选择编号样式会更新已有编号标题。其他新版编号列表转标题的范围仍受限制。

同一类平铺列表中的单个或连续项也可转为正文，中间项转换后两侧列表继续编号；选区覆盖列表与相邻根级正文时也可一起转正文。选中全部间隔正文并转回有序列表时，兼容的前后列表会合并并恢复连续编号；只选中部分间隔或序列、样式不兼容时保留原文。通过块菜单转正文会保留文字格式，段落样式及快捷键遵循既有格式清理规则。

新版序列支持正文、文字格式、行高、编号样式、折叠、同组回车和叶项删除；已验证的同级插入和写作接纳保留序列。符合条件的根级列表项可通过 Tab、Shift+Tab 或缩进菜单调整层级，并按目标层级接续编号；有效跨段续接中，原序列仍可在当前片段核实时也会同步后续编号。当未选项目会改变父项，或拆分交错序列、移走重启序列首项可能丢失原归属时保留原内容。其他跨段缩进、跨父及带子项移动和尚未支持的结构转换仍受限。

含新版编号序列的列表可以复制完整列表、同一段内的文字，或复制同一根级物理列表中由单段列表项组成的跨层部分选区。部分片段粘贴到空白正文后成为从 1 开始的独立列表，保留所选文字、格式和层级；纯文本剪贴板保留复制时的源编号及每层两格缩进。跨项剪切支持同父同层项、根项到其后代，以及两个默认编号父项之间的直接子项范围，可包含完整选中的中间深层子树：首尾未选文字合并，首项身份保留，一次撤销恢复原文字和编号。根项到三级子项、跨父项和同父同层项之间完整选中三级子树的样本已对照语雀；根项到直接子项及跨父项的范围允许无关父项含多段或深层项。涉及重归属的范围外深层子树、末项之后有未选深层项、跨物理列表和其他尚未支持的范围会保留原文并提示原因。

由独立的新版编号列表、根级正文段落和普通标题组成的跨块选区也可以复制，所选列表各自重新编号，正文、标题和文字格式保留。由普通正文或 v3 标题隔开的根级平级叶项列表，如果属于同一条连续编号序列，也可跨段复制：粘贴结果从 1 开始，并建立与源列表独立的续接。跨块选区中的编号标题须完整选中，部分选中、其他关联列表或其他块类型仍受保护；这些跨块复制样本尚未与语雀对照。

同层、同编号样式的普通多项片段，可以粘贴进新版列表的单个叶项，或替换同一父项下、同层且无子项的多个叶项中的文字。片段首尾分别合入选区前后的文字，新增项接续首个目标项的编号序列，未选中的其他序列保留；一次撤销恢复原内容、编号和选区。此入口要求封闭片段、兼容的段落格式和宿主属性，不兼容时保留原文。多行纯文本粘贴到上述叶项范围时，首行接在目标前缀后，其余行成为正文段落，原后缀另成接续编号的列表项。拆分后在前段新增同序列叶项，后段编号随之更新；删除只含一个叶项的中间片段时，已确认相容的前后片段继续接续。完整复制续接片段会建立独立关联，单段复制保留当时的编号而不连接来源。复杂嵌套、跨父项目标和部分结构变化仍待补齐。

待办、无序列表或标题隔开的有效编号续接也可以再次粘贴多行纯文本；已有间隔和关联版本保持不变，其他片段的编号继续联动。关联失效时保留原内容，不推测修复关系。

所测新版编号列表中，从首个根项选到其直接子项时，也可粘贴两项普通列表片段；未选中的同序列子项归属最后一个新根项，结果接续相应编号，撤销恢复原来的父子结构。语雀复制的所测列表片段使用可见 HTML 导入，来源编号不会覆盖目标编号；其他跨层级范围仍受保护。

默认起点、一个父项下只有直接叶项的旧嵌套有序列表，选中相邻或连续子项后粘贴多行纯文本时，可拆成列表、正文和续接列表。该操作在同一事务中转换为新版编号数据；撤销可恢复原嵌套结构。所测两段续接中，把后段首个子项拖到前段首个子项之前，会提升为根项，其后的子项继续编号；两段分别需要保留子项。

在已验证的三段续接中，空的中间子项退格先退到根级，再次退格退出列表；两步可分别撤销。

向正文粘贴多行纯文本时，连续空行会保留为空段落。接入方自定义的剪贴板解析器仍可决定粘贴内容。

新版继续读取原有 JSON 和 HTML。含新版编号及续接字段的内容需要使用支持该格式的版本编辑；旧版严格 JSON 读取器可能拒绝新增属性或不认识的版本，旧 HTML 读取器也不能保证保留编号序列和续接关系。中间项转待办或无序列表使用 v2 关系，转标题使用 v3 关系；只识别较旧关系的读取器无法正确编辑新版关系。

将指针移到正文块左侧，使用块操作柄可以拖动排序，或打开菜单进行转换、删除、复制、剪切、缩进和在下方插入。列表项可跨列表移动，普通块可将列表拆开；表格和复杂卡片作为整体操作。不可无损转换的类型会禁用转换。复杂嵌套和触屏拖动仍需进一步验证。

## 引用输入

在根级普通段落中输入 `> ` 可以创建引用；在只含一个空段落的根级引用中退格会回到正文。快速创建后立即退格及停顿后退格的撤销分组不同。空文档中连续输入引用和文字、快捷键转三级标题并清空时，所测快速操作可一次撤销；停顿后清空则单独撤销。嵌套引用和其他结构仍按现有编辑行为处理。

## 引用粘贴

粘贴无结构化来源标记的外部 HTML 时，引用外框会展开，包括嵌套引用和列表项中的引用；正文、标题、粗体、斜体、链接及列表层级继续保留。带有编辑器结构化复制标记的内容保留引用。此规则只作用于粘贴，直接加载 HTML 或 JSON 文档仍保留原有引用结构。

外部引用展开和语雀原生单段引用导入已通过定向 Chromium 回归及内置浏览器的真实剪贴板检查。已知语雀来源下，可见 HTML 的 `div.ne-quote` 会转成可编辑引用；Semlo 自身跨实例复制仍保留结构，撤销和重做按各实例独立处理。此处理不解析语雀私有载荷，也不代表支持完整语雀剪贴板或 Lake 数据格式。

## 链接

选中文字后通过工具栏插入链接，可编辑显示文本和地址；也可在空选区插入。支持锚点和相对地址。链接编辑涉及混合格式时，修改显示文本会保留选区起始文字的格式。

## 快捷入口

| 操作           | 快捷键或入口                                   |
| -------------- | ---------------------------------------------- |
| 打开插入菜单   | 空行输入 `/`，或按 `⌘/Ctrl + /`                |
| 插入或编辑链接 | `⌘/Ctrl + K`                                   |
| 清除文字格式   | `⌘/Ctrl + 反斜杠`                              |
| 查找替换       | `⌘/Ctrl + F`                                   |
| 调整字号       | macOS：`⌥⌘ + / -`；Windows：`Ctrl + Alt + / -` |
| 调整行高       | `⌘/Ctrl + Alt + [` 或 `]`                      |
| 退出连续格式刷 | `Esc`                                          |

字号按菜单档位变化；混合字号选区以起始文字的字号计算并统一应用。查找支持跨相邻文字格式匹配、结果导航、逐项或全部替换及撤销。基础 Markdown 输入快捷方式只负责输入时的格式转换，不能作为完整 Markdown 导入导出使用。

在已支持的空正文容器中键入的活动斜杠查询不会随快照保存，覆盖根级正文、引用、高亮块和折叠正文等场景；按 `Esc` 退出建议后会作为普通正文保存。标题和普通列表中的斜杠继续作为正文保留。详细范围见[保存与恢复内容](/persistence#选择保存格式)。
