# 语雀编辑器复刻进度

本页以 **2026 年 11 月 8 日**的工作区盘点为基线，随范围决策和模块验收更新。依据包括[当前功能与限制](/features)、各专题文档、相关源码入口和[语雀功能对照记录](/yuque-feature-matrix)。

## 范围与口径

- 当前范围包括选区浮动工具、第三方服务入口、投票和打卡等内容卡片。宿主服务和真实身份行为按实际环境核对。
- 多人协作、评论、Lake 数据格式兼容及[智能写作助手 #36](https://github.com/lzm0x219/semlo-editor/issues/36)排除在本轮开发和整合验收范围外。
- 每行是一个**已识别功能条目**，沿用历史对照表的拆分粒度；功能复杂度不同，未发现的功能尚未纳入。条目数和比例不能代表工作量、产品成熟度或最终整体复刻完成率。
- **已有主要实现**：当前功能文档和源码已有该条目的主要能力，历史记录标为“已有实现”；不表示所有交互已完成。**部分实现**：历史记录标为部分实现，当前功能文档或源码仍有相关能力或入口；仍有已知差异、依赖或待实现内容。**未实现**：未发现所需能力。
- **语雀已操作**仅表示曾在语雀测试文档操作过该条目的部分场景；**仅见入口**表示只观察到入口。它们不是完整的双方对照，也不是验收结论；具体观察及当时的测试范围见各组的历史记录。
- **验收记录**中的“已验收”及“样本通过”指对应 Issue 记录的实测范围。整项验收仍需核实功能、UI、交互、撤销、保存以及适用的宿主、框架和失败路径。保留在末列的缺口仍需按实际环境核对。

## 整合验收进展

21 个功能模块及后续画布专注编辑已按各自的样本范围完成验收。下表补齐了正文、标题、格式、列表和结构块的证据索引。Semlo 的空白页写作样本覆盖 11 节正文、查找替换、链接和文字格式。桌面 1280px 的 JSON 保存与窄屏 375px 的 HTML 保存覆盖编号列表、普通表格、单元格撤销重做及标题折叠恢复。

语雀与 Semlo 另用同一份 HTML 长文，核对多级标题、编号列表、普通表格和代码块。双方均保留了首次刷新后的结构及内容，末段续写可撤销、重做，并在再次刷新后保留。Semlo 另外用含数据表和视频的文档验证了宿主从 JSON 改存 HTML 后重载、编辑数据表和撤销重做。Semlo 样本的存储由测试宿主提供。 [整合验收 #42](https://github.com/lzm0x219/semlo-editor/issues/42) · [长文对照记录](https://github.com/lzm0x219/semlo-editor/blob/main/engineering/validation.md#2026-11-20-长文整合验收)

Semlo 另在 375px WebKit 触摸模拟中核对表格编辑、撤销重做和标题折叠。测试宿主通过 HTTP 将 HTML 写入磁盘，关闭原浏览器会话后可重新打开，续写保存后刷新也能恢复。

仍需核对的内容包括复杂跨块组合、实体触屏及生产宿主存储。真实上传、提及、互动和加密服务需要相应接入环境。已观测到的第三方预览拒绝及失效示例按下表保留。

## 更新规则

完成具体修复后，应同时更新该行的实现状态、剩余差异和可复核的对照或测试记录；只有整项范围和验收证据明确后才标为“通过”。新增发现的语雀功能应先加入清单并重新计算分母。真实上传、搜索、身份、权限及第三方服务结果需要注明所用宿主与环境，不能用模拟服务替代。
