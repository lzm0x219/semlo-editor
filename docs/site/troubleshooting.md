# 常见问题

## 编辑器没有样式

确认应用入口引入了样式：

```ts
import "@semlo-editor/core/style.css";
```

还要确认 semlo-editor 已执行 `pnpm build`，且应用安装的是包含 `dist/` 构建产物的本地包。修改组件库源码后，重新构建并按包管理器的方式更新应用依赖。

## 刷新后内容消失

编辑器不提供持久化服务。通过 `onChange`（Vue 为 `change`）获取快照，将 `json` 保存到应用自己的存储，并在下次创建编辑器时作为 `content` 传入。详见[内容保存与恢复](/content-and-integrations#内容保存与恢复)。

## 图片或附件无法上传

检查是否提供了 `uploadImage` 或 `uploadAttachment` 回调、上传接口是否成功，以及回调返回的地址是否可供访问。可通过 `onError`（Vue 为 `error`）查看编辑器报告的错误。`uploadAttachment` 同时用于附件、本地音频和本地视频；上传服务由应用自行提供。

## 找不到本机字体

字体菜单依赖浏览器的 Local Font Access API 和相应授权，支持情况取决于浏览器和运行环境。安装新字体后，可在字体菜单中点击搜索框旁的刷新图标。字体文件不会随文档保存或上传，在其他设备缺少该字体时会回退显示。

## 设置内容后没有触发变更回调

这是 `setContent()` 的行为：程序设置内容不会触发 `onChange`。如需保存程序写入的内容，应由应用在设置时自行处理。若内容无效，编辑器会通过错误回调报告；框架组件接收外部内容更新时也使用这一机制。
