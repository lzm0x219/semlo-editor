# 用显式续接连接拆分的编号列表

语雀将列表拆成正文和多个列表片段后，前段新增成员仍会改变后段编号，保存重载后也如此。各物理列表的局部序列 ID 不能标识跨列表关系；本决策在 [ADR 0001](0001-numbering-sequences.md) 的局部序列之外增加版本化续接，拆分时原子写入关联，后段起点随前段成员变化并参与同一次撤销历史。

续接作用于明确相连的根级列表：v1 允许普通段落隔开；v2 还允许待办或无序列表隔开，用于单序列平铺列表中间连续项转换后保持编号联动；v3 再允许标题隔开，用于单个或连续中间项转标题。格式刷转换简单平铺有序列表中间项时，同样按目标块使用对应版本连接两侧。转换回有序列表时，仅在完整选中间隔项且前后序列、格式和身份可确认的情况下合并。完整复制时分配新关联，单段复制不携带源关联，避免独立内容误连。跨段部分复制对同一初始序列的根级平级叶项建立从 1 开始的新续接；v3 的标题间隔也可保留关联，部分选中编号标题及复杂序列仍受保护；这一复制行为尚未与语雀对照。删除只含一个叶项的中间片段时，仅在前后序列身份和来源均能确认的情况下重新续接；其他情况保持内容，不猜测关联。

旧内容没有续接字段时，读取和无关编辑不会迁移；所测旧嵌套列表的跨项纯文本粘贴会在同一事务内生成续接。有效的跨类型 v2、v3 续接可再次通过多行纯文本拆分，保留链版本和已有间隔；失效链不推断修复。新 JSON / HTML 包含该字段；旧版严格读取器可能拒绝不认识的 v2 或 v3，旧 HTML 读取器不能保证保留续接。空项退格、跨父层、带子项及其他结构的原生行为尚未全部对齐。

平铺同序列的中间项转正文使用 v1；全部间隔正文转回列表时，仅在两侧编号、样式和结构可确认时合并。部分间隔或不兼容结构不猜测合并关系。

格式刷支持有效根级平铺续接的单项转换；按目标类型升级整条链，单项中间片段移除时连接前后。以编号项为来源刷相邻正文时，新增项继承所选来源的序列，交错序列也各自计数。语雀对应组合尚未对照。

有效续接中的列表项调整层级时，若原序列在当前片段仍有可核实成员，按目标层级重建成员归属，并在同一事务更新后续片段的起点。新增序列身份避开整条链中已有的定义；失效链、原序列无法在当前片段核实或其他不能保全归属的结构仍拒绝操作。语雀对应缩进组合尚未对照。

已有续接链中的同序列平铺片段转换为待办或无序列表时，保留其余片段的编号联动；整段转换会重新连接两侧，v1 链在同一事务中升级为 v2。转换后的完整中间范围可在两侧编号及样式匹配时接回，即使两侧另有正文或 v3 标题；间隔内容不移动。失效链不推断修复，链两端整段转回的身份尚未覆盖。升级后的 JSON / HTML 对旧版读取器的限制与其他 v2 数据相同。

平铺交错序列的中间项转换时，每个待办项、无序项、正文或标题保存 `semloEditorListSequenceConversion`，值为包含版本、续接边和原序列 ID 的 JSON 字符串；HTML 对应 `data-semlo-editor-list-sequence-conversion`。有效续接链的中间片段也可转为正文或标题，完整移除中间片段时连接两侧；涉及标题时在同一事务中升级整条链。只有完整选择转换范围、两侧关联与各序列来源可核实，才按逐项身份接回，原有的正文或标题间隔保持不动。拆分项继承原身份；正文、标题、待办和无序列表之间的受支持转换保留身份。完整复制续接时同步换新边 ID，单独复制间隔项则移除来源标识，避免与原文档误连。链两端整段、部分选择和复杂嵌套仍有边界；语雀对应行为尚未对照。

既有内容的快照不会因读取或无关编辑添加这个字段；直接使用底层 Tiptap `editor.getJSON()` 读取正文和标题时可能看到值为 `null` 的属性。含新标识的内容可能不被旧版严格读取器接受；过滤自定义 HTML 属性的宿主也会丢失标识，此时不能保证原身份恢复。失效或缺失关联不应按相邻编号猜测。
