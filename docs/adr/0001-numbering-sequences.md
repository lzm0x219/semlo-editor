# 用局部身份保留编号序列

语雀同父同层拖动的实测结果包含 `1、1、1、2、2`，现有每层单计数器加重启标记无法表达。采用列表级、带版本的编号序列定义和列表项局部成员标识；起点只存一份，显示值按每条序列的成员顺序派生。相较于每项重复存起点，这样可在重启和继续编号时集中维护一致性；不保存当前显示数字作为另一份权威。

旧 JSON / HTML 没有新字段时继续使用原算法，读取、保存和无关编辑不自动迁移；首次受支持的重排在同一事务内物化序列并移动成员；所测默认旧嵌套列表的跨项纯文本粘贴，以及格式刷将旧平铺列表中间项转为其他块类型，也在对应事务中物化并拆分。序列身份仍只在所属物理列表内解释；后来发现语雀允许拆分后的列表继续计数，因此仅通过 [ADR 0002](0002-numbering-continuation.md) 的显式编号续接连接片段，不能按相同局部 ID 推断关联。

新格式校验版本、起点、成员引用及逻辑父项和层级。未支持的结构操作明确拒绝，不能丢弃身份后按旧规则重编号；新版本保留旧内容，但旧版严格 JSON 读取器可能拒绝新属性，旧 HTML 读取器也不能承诺保留编辑语义。2026-11-07 接线、父级独立25项交互、38项旧回归、72项模型/事务检查及实际浏览器图像核验完成后接受此决策；整项列表功能仍按当前保护范围继续推进。

序列定义还需保存初始或手动重启的来源，菜单资格由来源和当前成员顺序推导，不绑定原先点击过重启的文字项。首个直接子项没有同级前驱时，实测仍能先重启再继续，数字不变但来源及菜单资格变化；实现不能因此省略事务。原生私有数据未读取，本决策仅定义 Semlo 自身的表达。

部分跨项复制创建独立片段：在已验证的同父、同层、无子项范围中，纯文本保留源可见编号，富文本以封闭的普通列表从 1 开始，不携带源序列身份或起点。这对应语雀所测 a/a/b 片段粘贴为 a/b/c、b/c 片段粘贴为 a/b 的行为；源文档不变，完整列表复制仍保留自身结构。剪切只在已定义端点的范围中合并首项前缀与末项后缀，保留首项身份和范围外成员；一次撤销恢复全部序列数据，不跟随原生样本中撤销丢失重启边界的异常。

随后对照补充根项和直接子项跨层复制：所选片段保留层级、以独立列表重新编号。复制已扩展到同一物理列表内由单段项组成的更深跨层范围，三级复制样本尚未对照语雀。剪切支持根项到其直接子项，以及两个默认编号父项之间的直接子项；后一种将未选中的末父项子项接到首父项的初始序列。需要同一根级物理列表、可核验的初始序列和兼容的段落属性；其他跨层剪切继续保护原文。

封闭的普通多项片段粘贴进根级新版列表的单个叶项，或替换同父同层的多个叶项时，接续首个目标项的编号序列。仅接受同层、同有效编号样式且段落格式与宿主属性兼容的片段和目标；首项合入目标前缀，末项接回后缀，全部新增成员继承首项局部身份，保留原序列定义、起点、来源及范围外成员。来源身份不会重建，属性冲突及未定义结构仍拒绝；粘贴作为一个独立历史操作。单叶项目标已用 level 0/1/2 样本核验，3–8 沿现有模型支持；跨项目标的语雀样本只覆盖 level 1，不称其他层级已实测。

多行纯文本粘贴进单个叶段落或同父同层的多个叶项时，首行合入目标前缀，其余行成为普通段落，目标后缀进入另一物理列表。拆分后每个列表仍持有局部序列定义；新后缀项接续首个目标的序列，其他序列的起点扣除已选中删除的成员，再保留剩余成员的相对编号。拆分与粘贴是一个历史操作；已核对的前段新增项联动后段行为由 ADR 0002 处理，其他结构和操作仍待核验。
